# YZboard 2.16.2 与管理端 0.98.1 发布

维护者：P0me1oo。日期：2026-11-12。

[面板 v2.16.2](https://github.com/P0me1oo/YZboard/releases/tag/v2.16.2) 与[管理端 v0.98.1](https://github.com/P0me1oo/YZboard-Dash/releases/tag/v0.98.1) 已发布并设为 Latest，面板公开、管理端私有的访问范围保持。Solid-US LA 已完成生产部署，见[部署记录](deployment-2.16.2.md)。

## 范围与来源

本版包含此前全部未提交更新：2.15.1 的中转禁用路由数组修补、2.15.2 的插件安装状态保护、2.16.0 的前置池动态负载/按落地健康/运营商 DNS、2.16.1 的国内运营商统一纯真，以及 2.16.2 的节点迁移后旧日志阻塞修复。

面板固定源码 `6aa59b80666d6f8ccb6a0af7692e681277d9ce28`；管理端固定源码 `a59dede5fc23b1e8b6e01497c4e112d5809de015`。管理端源码映射逐项匹配当前源码，274 份集成文件与构建产物按既定映射注释清理规则一致。发布后记录单独提交，版本标签和安装包保持固定。

## 验证与附件

- PHP 8.4.27、SQLite：完整 1,846 项、34,937 断言通过；12 项 MariaDB 专项按条件跳过，并在下述两套环境完成。
- MariaDB 11.4.8、生产同版 12.3.3：分别完整 1,846 项、34,953 断言通过，无跳过；启用严格分组与快照隔离，使用独立 Redis 8.0.2。
- Node 24.22.1：3,122 份源码检查、162 项行为、446 个浏览器场景、正式构建、资源与开发模式检查全部通过；面板五项资源契约通过。
- 开始时本机缺少 phpredis，相关检查失败或跳过；在任务目录补齐扩展后重新完成上述三套完整回归，没有将初次结果计为通过。正式源码无需因此调整。
- GitHub Actions 仍因账号账单锁定未执行；面板运行编号 `43169441352`，管理端 `43169437147` 未能启动。本次依据本机隔离环境的实际完整验证结果发布。

两仓库各提供安装包、`release.json` 和 `SHA256SUMS`，共六份附件已下载并逐项匹配。面板使用匿名公开下载，管理端使用已授权 GitHub 下载。源码包包含 `composer.lock`，不包含真实环境配置、本地规则或临时测试数据库；管理端包不含源码映射。完整摘要见[核验记录](release-2.16.2-verification.json)。

## 使用与兼容

本版有兼容加列迁移，保留旧分配状态；生产部署已执行。现有 Agent 无需升级，旧日志通过自动重试恢复。

运营商 DNS 的权威端准备门禁继续为关闭状态：四台权威需另行完成 Lua、ECS 和区域传送验证后才能启用。发布与面板部署不自动修改权威 DNS，具体条件见[动态调度](front-dynamic-scheduling.md)。未发布 Docker 镜像或升级运行节点。
