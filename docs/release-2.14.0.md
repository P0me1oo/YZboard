# YZboard v2.14.0 发布记录

维护者：P0me1oo。日期：2026-11-10。

[v2.14.0](https://github.com/P0me1oo/YZboard/releases/tag/v2.14.0) 已正式发布并设为 Latest，固定源码 `4a07fc4aa93cb08e2fcea7ebf84982b2dd3b4404`。本次以 v2.12.1 为基线，仅加入已删除服务器的 Agent 自动解绑；管理端沿用 0.96.1。原工作区 2.13 系列未发布改动和生产 2.12.2–2.12.5 的独立部署补丁未合入本包，原有工作区修改保留。没有部署服务器或发布 Docker 镜像。

## 功能与迁移

删除服务器、解除节点关联和保存删除凭据在同一事务完成。删除凭据只保存编号、令牌摘要与时间；配套 Agent v2.37.0 使用随机挑战确认后移除本机对应绑定。停用、旧令牌和未知身份不触发自动删除，升级前未保留删除凭据的记录仍需手动解绑。新增迁移和接口见[自动解绑](machine-binding-deletion.md)。

启用需要先完成面板新增迁移，再更新 Agent。回退程序可保留新增表，避免重新丢失离线 Agent 所需的确认记录；回退到不含本功能的面板后，新 Agent 保留配置。恢复已删除的服务器记录时，现存身份优先于历史删除记录。
