# 节点地区分类与批量排序

适用版本：面板 `1.59.1`、管理端 `0.34.1`。本功能在 `1.59.0` / `0.34.0` 开发阶段完成，本次合并交付；Node 沿用 `v2.9.0`。

## 国家与地区

节点管理上方增加“国家/地区”筛选，可以多选，并与名称、协议、内核、服务器、权限组筛选一起使用。选项只列出当前节点名称识别到的国家或地区，无法识别的统一显示为“未识别”。更改筛选后回到第一页。

分类复用服务器名称识别表，支持表内的中英文国家或地区名称、城市、常用大写缩写和已有国旗字符。例如“香港 01”“Hong Kong”“HK01”归为香港，“Tokyo”归为日本。英文名称不区分大小写，缩写按大写匹配。修改节点名称并刷新列表后重新分类。

同一名称包含多个地区时，取最先出现的具体国家或地区；同一位置优先匹配更长名称，例如“中国香港”归为香港。“中国电信”“中国移动”“中国联通”和“CN2”不作为所在地依据。仅写“亚洲”“欧洲”等泛称或未收录写法时归为“未识别”。分类用于管理端筛选，不写入节点配置，也不依据 IP 推断所在地。

## 批量排序

1. 点击“编辑排序”，勾选需要调整的节点。
2. 页面底部居中显示已选数量，以及“移至顶部”“上移一位”“下移一位”“移至底部”四个按钮。
3. 调整完成后点击“保存排序”。关闭操作栏只清空选择，已调整的草稿仍保留。

所选节点保持原有先后关系；连续选中的节点一起移动，间隔选中的节点各向对应方向移动一位。到达首尾或选中全部可见节点时，对应按钮禁用。无选中节点时操作栏隐藏。手机端可进入排序、选择单个节点或全选，并使用相同操作栏。

批量移动以当前筛选结果为范围：只交换可见节点占用的位置，隐藏节点的位置保持不变，隐藏的已选节点不计入操作栏。清除筛选后可以检查完整顺序。保存仍通过原有排序接口提交所有节点的顺序。

进入排序模式会清除临时列头排序，避免覆盖手工调整；原单节点拖拽继续可用。保存期间禁止重复提交和继续移动。保存或随后刷新失败时保留排序草稿与选择，可直接重试；成功后退出排序并恢复正常分页。离开页面或直接刷新页面会丢弃尚未保存的草稿。

## 交付范围

功能在 `YZboard-Dash` 源码实现，构建后通过已有同步脚本交付到面板。无新增数据库迁移、节点通信或核心改动。管理端本地模拟测试不代表真实生产环境联调。
