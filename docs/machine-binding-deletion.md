# 删除服务器后的 Agent 自动解绑

面板 2.14.0 配套 Agent v2.37.0，本次发布以 v2.12.1 为基线，仅加入自动解绑，管理端沿用 0.96.1。工作区此前的 2.13 系列未发布改动未纳入。

管理员删除服务器时，节点解除关联、服务器删除及删除凭据保存属于同一数据库事务。新增迁移 `2026_11_10_000001_create_machine_binding_deletions` 创建 `v2_machine_binding_deletion`，仅保存服务器编号、删除时有效令牌的 SHA-256 摘要及删除时间，不保存明文令牌，不保留服务器名称、节点或负载数据。

`POST /api/v2/server/machine/binding-status` 接收 `machine_id`、`token` 和 64 位十六进制随机 `nonce`。有效机器返回 `active` 或 `disabled`；已删除且原凭据匹配时返回 `deleted`、对应编号、原随机挑战及 HMAC-SHA256 确认，所有结果禁止缓存。确认内容为 `yz-agent-machine-deleted-v1\n<编号>\n<挑战>`，HMAC 密钥为原令牌的二进制 SHA-256 摘要。

未知编号、旧令牌及无删除记录的身份统一拒绝，不将通用鉴权失败当成删除通知。现存服务器记录优先，避免数据库恢复或编号重用时错误清理。状态查询不更新心跳，不把失效的旧进程显示成在线。

删除凭据持久保留，离线 Agent 重连后可以补清理。Agent 启动、安装合并及每 30 秒检查删除状态，核实后清除对应本机绑定与独占凭据；运行中沿用配置重载，最后一个绑定移除后等待新绑定。其他绑定、证书、待补报流量和备份保留。

旧 Agent 继续按原有接口运行；新 Agent 遇到旧面板、禁用、鉴权失败、网络错误或公开 HTTP 面板均保留配置。面板升级前已经删除的服务器没有凭据可核实，仍需手动解绑一次。旧版整文件加密恢复副本需人工处理；常用的按实例加密配置支持自动解绑。

首次启用需要面板完成新增迁移，并配套新版 Agent。回退程序时可保留新增表，不能删除该表后继续运行依赖它的面板版本；恢复已删除服务器数据后，现存身份优先于历史删除记录。

验证使用 PHP 8.4.27、SQLite 和隔离的 MariaDB 11.8.6（启用严格分组），覆盖真实管理删除入口、解除关联、事务失败回滚、有效确认、停用、令牌重置、未知编号、编号重用及输入验证。当前不是生产 11.4 的发布核验。
