# 套餐多权限组

套餐可以选择多个权限组。用户购买、试用或由管理员分配套餐后，可访问任一所选权限组包含的节点；同一个节点即使属于多个组，也只向用户展示和下发一次。

升级时数据库迁移会为套餐和用户增加组列表。旧记录无需回填：组列表为空值时仍按原单组字段识别。新记录同时保存首组字段，兼容旧版读取。管理员选择“强制更新”时，现有套餐用户的组列表会被新列表覆盖，并刷新原组和新组的节点；不选择时，现有用户保持原权限直到再次分配或购买套餐。

回滚到旧面板后只识别首个权限组，其他组不会继续生效。回滚前应检查已售套餐与用户权限，并保留数据库备份。

用户管理中的在线公网 IP 详情增加 ASN 和网络名称，使用 [IP2Location.io](https://www.ip2location.io/) 的免密钥查询接口；现有地区和运营商继续来自本地 IP 库。外部查询结果缓存七天，每天最多查询 1,000 个未缓存的地址。接口超时、失败或限额耗尽时显示“ASN 未知”，不影响设备数及原有本地信息。
