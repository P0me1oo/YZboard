# 节点 Reality 参数统一

面板 2.4.0、管理端 0.89.0 在节点管理顶部“操作”菜单增加“统一 Reality 参数”。面板 2.4.1、管理端 0.89.1 起，密钥与 Short ID 的界面与添加节点一致。

先勾选至少两个实际运行的 VLESS 或 Trojan Reality 节点，再选择统一方式：

- **统一成某个节点**：选择本次已勾选的基准节点，保存时读取该节点当前参数并应用到全部已选节点。
- **手动填写**：填写共同的握手域名、握手端口、私钥、公钥和 Short ID；公钥留空时由私钥派生，明确填写时检查密钥是否匹配。私钥输入框右侧的钥匙按钮生成密钥对，Short ID 输入框右侧的刷新按钮单独生成 Short ID，两者不相互修改。Short ID 可以留空。切换统一方式保留本次手动输入，关闭窗口后清空。

两种方式都只统一前置负载分配要求一致的 Reality 密钥对、短 ID、握手域名和握手端口。节点连接地址、公网端口、内核、传输、流控、权限、独立回源及防盗用设置继续保留。前置池仍检查其他连接参数、服务器与地址冲突；当前支持范围见[前置负载分配](load-balancer.md)。

已加入前置池的节点只允许统一为与池模板一致的参数；需要更换池参数时，在前置池中调整。防盗用与独立回源冲突时拒绝整批保存。任何校验或数据库写入失败都不留下部分更改，弹窗保留输入供重试，提交期间禁止重复操作。

操作支持一次选中 2–500 个节点。只有已选节点会改变，手机普通列表也提供勾选框。使用旧参数的直连客户端需要更新订阅；离线节点恢复后读取已保存配置。沿用现有配置下发，不需要数据库迁移、Agent 或核心升级。
