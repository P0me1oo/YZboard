# 用户管理

## 列显示与排序（面板 1.36.0、管理端 0.17.0）

表头与下方数据左对齐。“显示列”可以开关在线设备、连接数、上传/下载速度、状态、订阅、权限组、流量、到期时间、余额、佣金和注册时间；隐藏后其他列自动使用释放的空间。邮箱、编号、选择框和操作入口保留。选择保存在当前浏览器，刷新后和窄屏卡片继续生效。

“当前连接数”改为“连接数”。点击连接数、上传速度或下载速度右侧的现有排序按钮，可切换从低到高、从高到低。后端先对筛选后的全部用户排序，再分页，未知值始终放在末尾，部分数据按已确认的下限排序；相同数值按用户编号倒序排列。切换排序返回第一页。选用这三种排序时，每十秒重新获取列表以更新跨页排名，保留勾选和编辑内容；未选用时仍由实时通道更新当前页数值。

本次随面板一并保留实时网速功能。Node `v2.1.0` 不上报网速，显示未知；需要 Node `v2.2.0` 或兼容上报版本才能显示实际速度。管理页布局、列开关和连接数排序不要求升级 Node。

## 实时网速（面板 1.36.0、Node v2.2.0、管理端 0.17.0）

用户管理列表在当前连接数后展示“上传速度”和“下载速度”，窄屏卡片同样显示。方向以用户为准，使用 B/s、KB/s、MB/s 等单位，按 1024 换算。速度是最近一个采样周期的平均值，不是测速结果或套餐限速。

- Node 复用每秒累计流量采样，按真实经过的时间计算速度，通过现有实时状态通道上报；WebSocket 不可用时沿用十秒 HTTP 兜底，页面更新频率会降低。
- 汇总用户在实际入口上的速度，中转落地不再重复计入，不乘计费倍率。仅推送当前页订阅的用户，不新增独立页面或历史曲线。
- 首次采样、采样失败、超过五秒未采样或计数回退时重新建立基准，不把历史或补报流量显示成网速；下一次有效采样恢复显示。
- 有效完整空快照表示零速；旧 Node 未提供网速或超过 35 秒没有新状态时显示“未知”。部分相关入口缺失时显示 `≥`，悬停可查看说明和最早数据更新时间。
- 网速只在运行内存和面板当前状态缓存中替换，不写用户数据库或流量批次，不存历史。计费、流量补报、限速和连接数原有流程保持不变。

实际网速需三个项目配套交付，本次面板发布不包含 Node `v2.2.0`；旧 Node 可以继续使用其他管理功能。发布和验证状态见 [兼容矩阵](../YZ_COMPATIBILITY.md)。

## 增加时长（面板 1.34.0、管理端 0.15.0）

在用户行的“操作”中选择“增加时长”，或勾选多个用户后通过列表上方“操作 → 增加时长”批量执行。输入增加天数并确认，完成后刷新列表，提示实际增加与跳过的人数。未勾选时批量入口不可用，已勾选的跨页用户也包含在本次操作中。

- 只处理明确选中的用户；未到期用户从原到期时间增加，每天按 86,400 秒计算，保留具体时分秒。
- 已到期（含恰好到期）、永久有效和已不存在的用户跳过，不重新开通。最终状态以后端执行时为准。
- 天数范围为 1～36,500 的整数，每次最多 1,000 个用户；最终到期时间不能超过公元 9999 年。
- 同次提交重复用户编号只处理一次；另一次明确确认会再增加相应天数。提交中禁用按钮；请求失败时保留输入，应刷新核对结果后再决定是否重试。
- 事务中按用户编号顺序加锁，读取最新到期时间；出现校验或保存错误时回滚整批。通过模型更新保留节点同步和流量重置日期重算，不重置已用流量、不修改套餐或额度。

接口为管理路由下的 `POST user/extendDuration`，请求包含选中用户编号数组 `user_ids` 和整数天数 `days`，响应 `data.updated`、`data.skipped` 分别为实际增加人数与跳过人数。不支持以筛选条件或全部用户代替编号数组。

## 在线设备位置

展开在线设备详情时，位置和 ASN 共用 IP2Location.io 的免密钥查询；国家、地区、城市按服务返回原文展示并去重，运营商继续使用本地库。位置文字保留来源链接，不再单独显示 ASN 来源说明。

查询失败、返回位置为空、每日额度耗尽或缓存不可用时，位置回退本地库并附加“（本地）”；本地也查不到时显示“未知（本地）”。ASN 没有可用结果时显示未知。外部结果按 IP 缓存七天，失败暂存五分钟，每个 UTC 日期最多发起 1,000 次查询；沿用已有超时、并发和退避限制，不在用户列表加载时批量查询 IP。

## 到期时间

创建与编辑用户共用四个预设：一个小时、一个月、三个月、长期有效。都从点击时计算，不在旧到期时间上续加。

- 一个小时：当前时间加 3,600 秒，跨日也不改成当天结束。
- 一个月、三个月：目标月对应日期的 23:59:59；如果目标月没有该日期，则取该月最后一天。
- 长期有效：清空到期时间。

日历月份、星期跟随管理界面语言，中文界面显示中文。仍可手动选择日期；编辑用户原有的具体时间输入保持可用。

## 当前连接数

需使用能上报真实连接数的 YZ-Agent `v1.24.0` 或兼容版本。设备数、在线来源 IP 数、当前连接数不是同一项，本功能不互相推算。

面板保存每个实际入口最新的完整连接快照；重复报告替换而非累加，空快照表示该入口已无连接。汇总时不重复计入中转逻辑落地，权限组不同但实际报告了用户连接的入口也纳入。对于用户权限组覆盖的启用入口，缺失或超时的快照会使结果标记为不完整。

- 正常数字：所有应计入口都有有效快照。
- `≥ 数字`：部分入口无有效快照，数字仅是已确认的下限。
- `—`：没有有效数据，不能认定为零。旧节点不支持上报时也显示此状态。

页面在前台每十秒刷新，后台不持续轮询；接口读取失败时不继续把上次数据当作当前值。悬停数字可查看所用快照中最早的上报时间。采集速度受节点上报周期限制，不是秒级实时。

快照有效期为节点上报间隔的三倍，至少六十秒；默认六十秒上报间隔时，有效期为一百八十秒。过期数据不继续计数。数值只保存在缓存，不写入用户表；缓存丢失后等待节点下一次上报恢复。原有插件报告钩子和连接数限制不变。
