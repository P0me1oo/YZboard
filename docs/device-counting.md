# 设备计数与跨节点续期

## 1.39.1 修复范围

面板按同一用户的公网来源统计设备：IPv4 按单个地址，IPv6 按 `/64` 网段合并，并应用不计入设备数的来源名单。设备数量不等于手机、电脑的实际数量；切换网络后旧连接尚未关闭时，两个来源仍可能短暂同时占用名额。本次不改变这项规则。

此前面板对同一连接、同一节点的相同版本设备名单只发送一次；节点超过三十五秒没有收到名单就清除跨节点记录。即使节点仍正常上报、名单内容没有变化，也可能因此漏算其他节点上的设备。

本版对相同版本保留十秒内去重，之后重新发送完整设备名单，继续使用原版本号。五秒周期校准负责在没有变化通知时触发读取和续期，通常每十秒续期一次；定时器延迟和网络耗时会影响实际收到的时间。设备内容变化、新连接和主动完整同步仍立即发送。空名单同样续期，避免节点把已经清空的状态误认为缺失。

续期时间按物理连接和节点分别保存。成功交给发送缓冲区后才更新时间；发送失败不更新，下一轮重试。连接解除绑定时同时清除版本和发送时间。节点仍保留三十五秒没有有效设备快照时的过期保护，不使用负载心跳代替设备快照续期。

## 配套与升级

- 面板 `1.39.1` 修复设备名单续期；已支持当前实时协议和相同版本快照的旧 Node 可以直接受益。
- Node `v2.4.1` 统一 Xray 的连接记录，修复从不限设备切换到有限制、反向切换及并发变更时的漏算或关闭残留；已有连接保持，关闭时正确归还名额。
- 完整修复需要两端配套，部署时先更新面板，再更新 Node。只更新 Node 不能解决旧面板不续期的问题；用户无需强制刷新或重新导入订阅。
- 不修改管理前端、数据库、面板与节点的消息格式，也不更新两个核心 fork。发布状态与镜像来源以兼容矩阵为准。

## 验证

回归覆盖名单连续八十秒不变、空名单、发送失败重试、共享机器连接各节点独立续期、新连接与重新绑定，以及 Node 对相同版本续期、旧版本拒绝、真实失联过期和恢复的处理。Xray 另覆盖上限切换时保留原来源、关闭后设备与连接归零，以及并发变更上限。实际执行结果记录在兼容矩阵；本次不使用生产身份或连接服务器。
