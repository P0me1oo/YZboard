# YZboard 2.32.1 发布

日期：2026-11-28。维护者：P0me1oo。

v2.32.1 于北京时间 19:24:11 正式发布并设为 Latest，固定源码 `ec698d55a468a9505be2d6bc96d9ec50ed24e85c`。本次完成提交、推送、Tag 和 Release，未部署生产或发布 Docker 镜像。

## 内容与兼容性

修复设备锁繁忙的快速重试被误记为“节点 HTTP 请求耗时异常”。其他 5xx 记录为请求处理失败，真正耗时至少一秒的请求保留慢请求诊断；隐私策略、限频、原状态码与重试语义保持。

同时包含 2.31.0、2.32.0 的节点确认删除与服务器删除确认协议。内置管理端 0.112.0，相对生产 2.30.2 包含迁移 `2026_11_26_000001_allow_landing_pool_without_primary`。回退该迁移前需重新配置或删除缺少主线路的池，不自动删除池数据。

现有 Agent 可继续使用；服务器删除后自动解绑需要配套 Agent v2.57.0 支持，该 Agent 版本尚未正式发布，本次仅发布面板。依赖仍按原 `composer.lock` 安装，没有依赖升级。
