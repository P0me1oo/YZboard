# 隐私保护模式

面板 `2.2.0`、管理端 `0.87.0`、Agent `v2.31.0` 的本地实现支持在面板反复开启和关闭。此配套版本尚未发布或部署；以下说明以新行为为准。

面板 [v1.111.1](https://github.com/P0me1oo/YZboard/releases/tag/v1.111.1)、管理端 `0.81.0`、Agent [v2.28.1](https://github.com/P0me1oo/YZ-Agent/releases/tag/v2.28.1) 已发布，一并交付 `1.110.0` / `v2.27.0` 开发阶段的本地文件加密，保留原永久停用日志及保存后锁定。已开启旧设置的机器直接沿用；先更新面板，再更新 Agent。

面板 [v1.107.1](https://github.com/P0me1oo/YZboard/releases/tag/v1.107.1)、管理端 `0.78.0`、Agent [v2.26.0](https://github.com/P0me1oo/YZ-Agent/releases/tag/v2.26.0) 已发布，配套使用。

在“服务器管理”新建或编辑机器，调整“隐私保护模式”并保存。可以先下发配置、运行 Agent 后再开启，也可以提前开启后安装。保存后仍可关闭或再次开启；已开启的旧设置继续沿用，不自动关闭。

停用范围为该机器 Agent、节点和 Xray / sing-box 的全部运行日志，包括用户数量、在线统计、节点启动停止、连接信息、警告、错误和 Xray 崩溃日志通知。本地标准输出、日志文件和运行日志上报均停止；面板收到旧 Agent 或在途运行日志批次时确认并丢弃，不新增记录或通知。历史日志和本地已有缓存不会自动删除。

配套 Agent 在首次取得策略前保持静默；握手、机器发现和控制回报均可接收策略，运行中的机器在下次交换时应用开关。开启时停止日志，关闭时重新允许输出及上报，实际日志仍遵循面板日志设置和本地日志级别。重载、Agent 重启或整机重启均重新获取面板策略，本地日志级别不能覆盖面板开关。旧版面板没有策略字段时，新 Agent 继续静默。

同一进程有共享的日志和核心出口；任一身份开启隐私保护，该进程全部运行日志保持静默，直到所有活动身份明确允许日志。建议将需要保留日志和需要停用日志的机器分开运行。独立节点绑定若属于一台机器，同样使用该机器设置；未关联机器的独立节点不具备机器级开关。

这项设置不停止流量计费、在线状态、设备限制或代理访问记录，也不影响面板自身的系统、登录和管理审计记录。版本、状态等主动查询和操作系统的服务管理记录不属于 Agent 运行日志。设置不会隐藏程序身份，也不能阻止服务器管理员检查配置、内存或下发的用户列表。

Agent `v2.27.0` 使用原有认证身份向面板领取按机器派生的 AES-256-GCM 文件密钥。密钥仅在节点内存中保存；敏感配置、程序管理的证书、待确认流量和缓存加密落盘，重启后自动领取密钥恢复。启动所需的面板入口、身份、凭据引用及必要运维信息仍可读，`credentials.env` 继续由服务管理器读取。各实例独立恢复，冷启动需要面板可达；密钥领取失败时保留文件并自动重试，不降级为明文。

关闭后，Agent 自动解密受管理目录中的已有加密文件、实例配置及可确认身份的配置备份，后续恢复明文保存，文件权限仍为 `0600`。转换与运行中的文件写入互斥，保留流量、重试编号和扩展配置；重复开关不会重复累计。解密失败保留未完成文件及配置恢复信息，并自动重试。密钥接口在关闭后仍向已认证的原机器提供原密钥，因此先关闭再整机重启也能完成恢复；整机自动启动还需 Agent 服务已启用开机自启。关闭不会补回停用期间的运行日志。

关闭功能需要配套 Agent `v2.31.0`：旧 Agent 仍保留单向日志锁定，并忽略关闭状态下的恢复密钥，不能仅更新面板后直接关闭。应先更新面板和 Agent，再操作开关；本地未发布版本不作为服务器更新来源。

面板密钥接口沿用原有认证范围，响应禁止缓存。机器令牌只可领取本机密钥，旧式共享节点令牌保留原有节点访问权限。文件密钥根据数据库机器编号及应用主密钥派生；恢复面板须保留原数据库和 `APP_KEY`。轮换应用主密钥时，需在 `APP_PREVIOUS_KEYS` 中保留尚有数据使用的旧密钥，直到节点及需要的备份完成迁移。无需新增数据库迁移。

仅加密程序管理的文件；外部手工指定的共享证书和配置不自动改写。复制单独加密文件不包含密钥，但完整节点目录和有效启动凭据仍可用于向面板领取密钥。证书、历史备份、目录迁移及旧版回退的具体范围见[Agent 加密与恢复说明](../../YZ-Agent/docs/log-privacy.md)。

Agent `v2.26.1` 在保存、合并、清理和迁移配置或凭据时，将文件权限收紧为仅所属用户可读写（Linux `0600`）；安装记录也使用相同权限。已有文件曾放宽权限时，下次经这些入口保存会收紧；安装器升级同步应用。默认安装目录原有的仅所属用户可进入权限（`0700`）继续保留。这些措施限制普通系统账号读取，不限制宿主机管理员。

新版安装器通过标准输入向配置生成程序传递令牌，减少进程参数中的凭据暴露。显式选择历史版本时，通过能力探测保留其旧参数方式；历史版本不具备这项加固。

沿用原有机器字段，不新增数据库迁移。仍有机器开启隐私保护时，回滚该字段的历史迁移会被拒绝；应先正常关闭并确认节点转换完成，不能靠删除字段解除策略。不要删除并重建机器来替代普通编辑。

独立面板域名继续使用 Agent 的面板连接地址配置，HTTP 接口和 `/ws` 长连接均需可用；详见[Agent 连接地址](../../YZ-Agent/docs/log-privacy.md)。
