# IP 位置查询

面板 [`v1.95.1`](https://github.com/P0me1oo/YZboard/releases/tag/v1.95.1) 已发布，统一在线设备、入站 IP 统计和 Reality 检测的位置查询。此前 `1.95.0` 仅保留开发标签。

| 地址范围 | 地区来源 |
| --- | --- |
| 中国大陆 IPv4 | 纯真 `20260930` 本地库 |
| 其他地区 IPv4 | 官方 ip2region IPv4 本地库 |
| 全部 IPv6 | 官方 ip2region IPv6 本地库 |

IPv4 先读取 ip2region 的国家代码，`CN` 使用纯真；港澳台及其他地区使用 ip2region。纯真查询失败时回退 ip2region。运营商取自 ip2region；私网、保留地址、库不可用或无有效数据时显示“未知”。

PHP 查询包固定为 `zoujingli/ip2region v3.0.16`。两份数据库直接来自 `lionsoul2014/ip2region` 的完整提交 `f8b0792b0cd729f5b2593f690aeed225e49c1967`，生成日期分别为 `2026-10-14`、`2026-08-14`；随源码及镜像交付，运行时不下载。下载地址、文件大小和摘要见 [数据库说明](../resources/ip/README.md)与[固定来源清单](../resources/ip/ip2region.json)。生成日期不代表每个地址的原始数据采集日期。

外部 IP2Location.io 接口和 IP2Location.com 网页继续补充网络编号（ASN）、网络名称和风险属性，不覆盖本地地区。有效网络数据缓存 30 天，失败或缺少有效网络数据时缓存五分钟，沿用每个 UTC 日 1,000 次的查询上限及退避规则；外部失败或额度耗尽不影响本地位置。

入站地区及省份使用独立本地缓存：成功缓存 30 天，未知缓存五分钟。升级迁移只将旧位置缓存到期时间归零，下次打开统计或运行后台任务时重新查询；不删除 IP、出现历史、网络属性或流量数据。回退迁移保留记录，并让旧代码重新查询 IPv4 本地地区和 IPv6 外部地区。

管理端 `0.66.1` 将本地位置显示为普通文字，保留 IP 地址的外部查询链接；在线设备位置沿用“（本地）”标记。
