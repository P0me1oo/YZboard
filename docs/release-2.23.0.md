# YZboard v2.23.0 发布

维护者：P0me1oo。日期：2026-11-17。

[v2.23.0](https://github.com/P0me1oo/YZboard/releases/tag/v2.23.0) 已发布并设为 Latest，固定源码 `0beec26a0e04f94c69e23d800e74ff143ea32d27`，内置管理端 [v0.105.0](https://github.com/P0me1oo/YZboard-Dash/releases/tag/v0.105.0)，固定源码 `7ae4f93a4e6397cc904a8d99b25bceb0deaf6c0a`。

汇总全部本地面板与管理端更新：直出成员可保留中转落地，按线路分别执行权限和倍率；全部成员共用统一直出编号，直出池用户需刷新订阅。管理端允许勾选已有落地的成员，并显示原中转入口倍率。运行日志握手声明最低上传等级，配套 Agent v2.40.1 提前筛选普通信息和调试日志。没有新增数据库迁移、依赖或核心版本变更。

PHP 8.4.27 / PHPUnit 11.5.57：SQLite 完整 1969 项、36287 条断言通过，12 项 MariaDB 专项按环境跳过；与生产同版 MariaDB 12.3.3 严格分组下完整 1969 项、36301 条断言全部通过。使用专用 Redis 8.0.2，详细环境及补测见[完整检查](release-2.23.0-tests.json)。管理端 179 项行为及面板 5 项资源检查通过，274 份资源与 125 份 gzip 副本匹配，相关浏览器和构建结果按相同源码、产物复用。

面板和管理端六份附件均下载成功，大小、本机摘要与 GitHub 摘要一致；面板安装包可匿名获取，管理端保持私有。面板源码包包含锁文件和完整管理资源，不含真实配置、规则或源码映射，见[附件核验](release-2.23.0-verification.json)。GitHub 自动检查在启动阶段失败，没有执行测试步骤，不计作通过；发布使用上述本机结果。未发布 Docker 镜像。

Solid-US LA 已完成[生产更新](deployment-2.23.0.md)。直出池当前没有启用实例，因此本次未在生产创建混合线路或修改节点配置进行测试；相关功能实连验证沿用兼容矩阵中的隔离测试。
