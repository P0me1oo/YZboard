# Solid-US LA 更新至面板 2.26.0

维护者：P0me1oo。日期：2026-11-24。

通过 Lite MCP 将生产 `/root/yzboard` 从 **2.25.0** 更新为 **2.26.0**，运行账户为 `www-data`，内置管理端 **0.108.0**。Lite 节点当前名称为 Solid-US，已核对主机、目录、服务和部署来源。固定源码 `214b3d1a2b40c5f81c51150365175b97e8117aed`，附件来源见[发布记录](release-2.26.0.md)。

部署前 1,224 份运行文件与 2.25.0 基线全部一致。正式附件在独立目录匿名下载并校验，复用生产锁定依赖，Composer 安装及平台要求、PHP 语法和运行账户读取固定提交的检查通过。首次长命令因 Lite 执行租约到期退出，线上服务未受影响；重新核对连接和进程后，用临时 systemd 任务完成准备、切换和验收。

同步 10 项文件，包含版本配置、管理端入口、清单和新资源；1,230 份运行文件与正式来源全部一致。暂停三个面板服务和调度门禁，以 `www-data` 更新自动加载、执行 `xboard:update`、更新配置及视图缓存，随后恢复服务，切换耗时 **7.23 秒**。没有新增迁移，迁移记录仍为 152 条；没有全库导出。

验收：Web、Horizon、WebSocket、Nginx、MariaDB、Redis 六服务 active，三个面板服务自动重启计数均为 0；首页、管理入口、公开配置、主脚本、gzip、样式及入口脚本返回 200；未认证 WebSocket 返回预期 401，Horizon 正常。主脚本、gzip 解压及样式与正式资源一致，配置、插件和主题按 HMAC 核验未变。

49 台启用机器中 46 台近期心跳，109 个近期节点状态，无内核运行失败，与切换前一致。队列失败记录仍为 714 条，没有新增；切换后的服务日志未匹配致命、数据库、权限或内存错误。本次没有升级 Agent。详细结果见[部署核验](deployment-2.26.0-verification.json)。

保留 `/root/yzboard-deployments/2.26.0/` 的正式附件、准备源码、计划、原文件和缓存及验收记录，其中 `runtime-git.git` 为 Web 服务引用，必须保留。生产 `.git` 未改动。回滚来源为 **2.25.0** / `b556551f5256c71493c8358f1e07f60c90d7bc93`，原部署目录保留，本次无迁移。本次临时脚本、目录和已结束任务在交付前清理。
