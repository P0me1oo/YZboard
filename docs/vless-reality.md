# VLESS Reality 独立回源

面板 `1.96.0` / 管理端 `0.67.0` 将回源地址和握手域名分开配置，本地未发布。

在节点编辑中选择 VLESS 和 Reality，分别填写：

| 配置 | 示例 | 用途 |
| --- | --- | --- |
| 回源地址（dest） | `127.0.0.1:8443` | 节点实际连接的伪装站点地址，包含端口 |
| 握手域名（SNI） | `sni.example.com` | Reality 允许的握手域名及客户端订阅中的 SNI |

本机地址指运行 Node 的服务器；相应端口需要已有可用的 TLS 服务，证书与握手域名匹配。节点自身的连接地址、连接端口和服务端口仍单独设置。

回源支持域名或 IPv4 加端口。IPv6 地址使用 `[::1]:8443` 这样的格式，并选择 Xray；现有 Node 的 sing-box 地址拆分尚不支持 IPv6，面板会拒绝这类配置。

管理接口保存到协议设置的 `reality_settings.dest` 和 `reality_settings.server_name`；Node 配置接口分别下发为 `tls_settings.dest` 和 `tls_settings.server_name`。两个核心的既有 Node 适配均已读取这两个字段，本次不修改 Node 或核心。订阅继续使用握手域名，不输出回源地址。

旧节点没有独立回源地址时，继续使用原伪装域名和端口，端口为空时使用 443。打开旧 VLESS Reality 节点会将原地址带入回源输入框，保存后独立保留；不需要数据库迁移。旧字段 `server_port` 保留用于兼容，显式回源地址中的端口优先。

面板 `1.104.6` / 管理端 `0.75.2` 起，编辑握手域名时，如果回源仍使用原握手域名，回源域名同步更新，保留回源输入中的实际端口。清空握手域名再输入也会同步；手动设置的其他域名、IP 或本机回源不跟随修改。取消编辑不保存，保存失败保留修改供重试。本版本地未发布。

现有 Xray 防盗用模式会嗅探 TLS 域名并按域名重新回源。回源主机与 SNI 不同（例如本机 TLS 回源）时，需要关闭该模式；管理接口会拒绝同时启用的冲突配置，原配置保持不变。

“检测当前目标”分别发送回源地址和 SNI；使用可用结果时，分别回填实际目标与握手域名。检测仍只允许公网地址，本机或内网回源可以保存，但不能通过此扫描功能检测。详见 [Reality 目标检测](reality-target-scan.md)。

在检测窗口直接重试当前目标时继续使用原 SNI；修改检测目标文本后按普通目标扫描处理。输入不完整时清除上次检测结果，避免误用旧目标。
