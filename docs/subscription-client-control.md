# 订阅客户端限制

面板 [`1.68.3`](https://github.com/P0me1oo/YZboard/releases/tag/v1.68.3) 已发布，配套管理端 `0.41.3`，随面板镜像交付。固定来源与回滚参考见 [兼容矩阵](../YZ_COMPATIBILITY.md)。

## 使用方法

打开后台侧边栏「订阅管理 → 客户端限制」，选择限制模式和豁免权限组，在客户端列表中勾选需要加入名单的软件，可编辑名称和匹配关键词，也可添加或删除软件。页面采用对齐的紧凑行排列，手机纵向排列；停止编辑约 0.7 秒后自动保存完整规则，无需点击保存按钮。

新规则尚未填完整或超出限制时不提交，页面指出需补全的项目，已保存规则继续生效。自动保存期间可继续编辑；连续输入合并提交，同一时间只发送一份规则，随后保存最后一次修改，不用旧响应覆盖输入。保存失败保留草稿，点击「重试」或修改后再次提交，不无限重试。切换管理页面时立即提交待保存的完整修改；刷新或关闭浏览器前应等待「保存中…」结束。

| 模式 | 下载规则 |
| --- | --- |
| 关闭 | 不限制下载软件，默认使用此模式 |
| 白名单 | 只有命中已勾选软件规则的请求才能下载 |
| 黑名单 | 命中已勾选软件规则的请求不能下载，其他请求允许下载 |

预设 Clash，关键词为 `clash`、`mihomo`；预设 sing-box，关键词为 `sing-box`、`singbox`。两项默认勾选，但在关闭模式下不产生限制。预设不是完整的软件目录；其他上报名称需根据实际客户端补充。

关键词不区分大小写，按请求头中的软件名称（`User-Agent`）是否包含任意关键词判断。每行一个，也可用中英文逗号分隔；不使用正则表达式或通配符。例如 `Clash Verge` 是一个完整词组，`clash.*` 只匹配该字面文本。

软件名称只用于管理页面展示，不参与匹配。未勾选的规则不参与判断；最多 64 个软件，每个软件 1–32 个关键词，单个关键词最多 128 个字，软件名称最多 80 个字。

软件名称未知、为空或没有上报时：白名单拒绝，黑名单放行。白名单没有勾选任何规则时，只有全部有效权限组均获豁免的用户能够下载；页面会显示空白名单提醒。黑名单为空时不拦截。

用户至少有一个当前有效权限组，且全部有效权限组都在豁免名单内，才能跳过客户端限制。只命中部分组、没有有效权限组或豁免名单为空时，仍按客户端名单判断。判断使用账号当前有效的全部权限组，兼容历史单权限组账号；不以套餐定义替代当前账号的权限，也不使用多权限组账号残留的旧单权限组值。豁免只影响客户端检查，仍需通过原有订阅身份、账号封禁和订阅有效性检查。

## 订阅行为

两个现有入口都执行相同规则：短订阅路径和旧版 `/api/v1/client/subscribe`。短路径名称仍以站点设置为准。

链接里的输出格式参数（`flag`）只决定输出格式，不参与软件限制。例如软件上报 Clash，即使指定 sing-box 格式，也按 Clash 名称执行名单判断。软件上报名称可由请求方修改，此功能不能验证用户实际运行的软件，也不控制下载后的订阅转换或使用。

受限请求返回 HTTP 403 和纯文本「当前客户端暂不支持，请联系管理员。」，不输出节点或认证信息，拒绝响应禁止缓存。管理页不展示权限组规则说明或拦截提示，不提供自定义提示设置；客户端是否展示响应正文取决于客户端自身。

## 维护与交付

配置沿用管理员设置接口，将整份客户端限制规则（配置项 `subscribe_client_control`）一次保存。限制模式（`mode`）为关闭 `off`、白名单 `whitelist` 或黑名单 `blacklist`；软件名单（`clients`）保存展示名称、选择状态和关键词，豁免组列表（`exempt_group_ids`）保存权限组编号。后端校验结构、长度与权限组存在性，一次写入现有设置表，不需要数据库迁移。

前端独立页面为 `/finance/client-control`，保存失败保留输入，可直接重试。原「系统设置 → 订阅设置」的自动保存排除此对象，避免覆盖独立页面已保存的规则。

修改涉及 `YZboard` 和 `YZboard-Dash`；管理端源码构建后同步到面板的 `public/assets/admin`。无需修改 Node 或两个代理核心。验证和交付状态见 [兼容矩阵](../YZ_COMPATIBILITY.md)。
