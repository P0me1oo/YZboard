# 订阅设置与输出名称

本功能已随面板 `1.92.0`、管理端 `0.64.0` 发布。

## 管理入口

“订阅设置”和“订阅模板”移到侧栏“订阅管理”下面。原系统设置入口移除，旧地址仍会跳转到对应新页面；外观设置可以隐藏或恢复这两个菜单。

订阅设置参考 Telegram Bot 页面分为两页：

- **基础设置**：更换订阅、流量重置、新购／续费／更换套餐事件，以及订阅路径。
- **输出设置**：展示订阅信息、显示协议名称、自动添加国旗、在名称后添加倍率。

设置自动保存，切换分页保留当前输入。读取失败时禁止编辑，避免默认值覆盖已有配置；保存失败保留输入并提供重试。原订阅模板编辑器和各客户端模板保持可用，客户端限制与订阅防护仍使用各自页面。

## 自动添加国旗

默认关闭。开启后，根据节点名称中的国家、地区、城市或常见缩写，在名称前添加对应国旗 Emoji。识别词表沿用管理端的地区分类；多个地区同时出现时优先选择名称中靠前的匹配，同一位置优先选择更长的匹配。

已有国旗保留且不重复添加，无法识别时保留原名；不会查询节点 IP 或推测实际出口地区。若同时开启协议名称，前置国旗保持在协议名称前面。

## 在名称后添加倍率

默认关闭。开启后使用下载订阅时实际生效的倍率，包含分时倍率、中转入口继承倍率，以及落地自行设置的倍率。在名称末尾添加 `｜0.8×`、`｜2×` 等后缀，`1` 倍不显示，`0` 倍显示为 `｜0×`。

原名末尾已有相同格式的倍率时，以当前实际值替换，避免重复或显示过期数值。倍率变化后的名称在客户端下次更新订阅时生效。

这两个开关只改变订阅输出，不改后台保存的节点名称或计费规则。URI、YAML 和 JSON 订阅中的节点名称及选择组引用同步更新；剩余流量、到期时间、过滤数量等提示行不附加国旗、协议或倍率。节点筛选仍按原名执行。

本功能无需修改 Node 或两个代理核心，不新增数据库表或迁移；同一工作区中其他未发布功能的配套要求仍以兼容矩阵为准。
