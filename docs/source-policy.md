# 大陆来源 IP 拦截

面板 `1.53.0`、管理端 `0.30.0`、Node `v2.7.1` 包含此前未发布的来源策略，并接入普通 WireGuard，发布核验状态见兼容矩阵。

## 使用范围

在节点编辑页打开“屏蔽大陆来源 IP”。默认关闭，已有节点升级后保持原有行为。普通代理节点（含普通 WG）、前置入口和非 WireGuard 落地可分别设置。WG 中转落地不单独开启，用户来源在前置限制；普通 WG 按外层 UDP 来源拦截。

该策略判断代理核心看到的连接来源地址是否属于大陆网段，不判断用户国籍或所在地，也不限制用户访问大陆网站。经过其他代理或中转时，看到的通常是中转出口；启用受信任的来源地址传递时，以核心接收到的来源为准。IP 归属数据可能有误差。

大陆中转连接受保护节点时，应将它的实际出口 IP 填入“例外放行 IP”。最多 128 个具体 IPv4 或 IPv6 地址，不接受域名或网段。例外只跳过本项地区限制，仍执行原来的认证、线路权限和路由；不会改为直接出网。面板不自动猜测或放行前置出口。

前置入口启用后，来源限制同时作用于它接收的直出和中转请求。落地的来源限制独立设置；入口的开关不复制到落地。开关关闭时保留填写的例外，便于再次开启。

## 执行与数据更新

Node 使用两种核心共用的大陆 IPv4、IPv6 网段列表，来源为 [Loyalsoldier/geoip 的 cn.txt](https://github.com/Loyalsoldier/geoip/blob/release/text/cn.txt)。运行时本地匹配，不逐连接查询外部接口。Node 从大陆集合中扣除例外后生成来源拦截规则，置于自定义路由之前；规则只作用于本节点代理入口，不影响 REALITY 的本机伪装回源。

网段库首次启用时下载并校验，成功后保存到 Node 地理数据库目录中的 `cn-source.txt`。每 24 小时更新；后台每分钟检查是否需要刷新，下载失败至少间隔 5 分钟重试。同目录的多个节点共用缓存和下载锁，IPv4 或 IPv6 缺失、空文件、无效内容和全地址网段均拒绝使用。新数据校验和写入成功后才替换旧版本；集合未变化不重载。

首次没有有效网段库且下载失败时，该节点报错并停止接受代理业务；控制通道继续工作，后台成功取到网段后自动恢复。后续下载失败保留上一份有效数据和限制，并记录告警。开启、关闭、修改例外或有效网段变化通过现有核心重载流程应用，已有连接是否立即终止取决于核心重载方式，不承诺无中断或立即踢掉旧连接。

该功能不修改系统防火墙。普通代理请求在路由阶段被阻断，客户端可能先完成传输握手；普通 WG 在外层 UDP 入口直接丢弃受限来源。

## 兼容与回退

必须先使用配套的 Node `v2.7.1` 或更高兼容版本，再启用面板开关。旧 Node 会忽略新策略，面板保存成功不能证明旧节点已经拦截。

本次新增一个可空的节点策略列，不改用户、流量或已有协议参数。回退到旧 Node 前先在面板关闭本功能；新增数据库列可以保留。面板发布状态与验证记录见 [兼容矩阵](../YZ_COMPATIBILITY.md)。本地修改完成不代表服务器已经更新。
