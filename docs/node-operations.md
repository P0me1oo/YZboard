## 管理入口

- 节点管理：“链路健康”查看本机监听、实际出站、失败原因、最近检查与 24 小时样本；详情选择跟随全局、开启或关闭，或立即检查；检查地址和间隔在全局设置中统一管理。配置保存成功不弹提示，Agent 应用失败显示节点错误。
- 流量统计 → 对账：按节点和日期查看已结算实际流量与扣费流量，单独列出当前待补报、待结算和失败批次；只有查询，没有改流量、补账或扣费操作。
- 节点管理 → 证书管理：查看证书有效期、指纹、签发者、续期结果和核心加载情况。自动申请的 ACME 证书可请求续期；编辑入口跳转现有节点证书表单，继续使用原有配置校验。
- 节点管理和前置负载分配的“查看拓扑”：从数据库生成前置池、入口、逻辑落地及主备关系，点击查看关联或编辑。实线是配置关联，不将其声称为实时流量路径。
- 套餐编辑 → 自动临时限速：设置触发方式、速度口径、阈值、持续时间或窗口超阈秒数、临时上限及执行时长；沿用“同步更新已有用户”。用户列表下载速度处显示当前临时上限，提示包含节点及结束时间。

## 运行语义

### 配置应用

Agent 的 Xray 对只有路由变化的配置热更新，原实例和存量连接保留；出站、监听、TLS、用户或静态路由参数同时变化时沿用原重建方式。自定义配置文件保守重建。失败停止当前节点，既有权限撤销和计费流程保持；检查设置和续期指令本身不引起核心重建。

运行错误经 Agent 与面板两次脱敏。状态从已有认证节点通道回传，确认旧 Agent 版本后显示待升级，未收到状态显示等待状态，超过 90 秒未收到状态显示无最新结果。核心停止时清除当前健康结果并显示已停止，恢复后重新检查。检查结果按配置指纹淘汰重载前结果，面板只保存有界元数据。状态按进程编号和递增序号去重，旧进程退出后不能通过迟到消息覆盖新状态，不依赖节点时钟判断配置状态。

### 检查范围

默认关闭，由管理员启用。Agent 从节点本机检查 TCP 监听，并通过正在运行的核心默认及中转出站访问指定的 HTTPS 公网目标，内部中转包含真实代理握手。UDP 入站（包括 XHTTP HTTP/3）不通过 TCP 探测，界面显示未检查。

不覆盖客户端到入口的公网线路、CDN 或入口用户认证；延迟不是用户所在地延迟。目标禁止认证信息、查询参数和重定向；所有解析地址通过公网校验，连接固定到校验后的 IP，仍验证 HTTPS 域名证书。探测不进入用户计费或设备统计，但会产生少量网卡流量。

每轮最多 30 秒，间隔 30–3600 秒，每轮最多默认出站和 16 个中转出站，最多四路同时检查；整轮截止后的未完成项标为未知，实际连接失败才标为故障；超过时明确显示部分检查，不把未测线路判为健康。只诊断，不自动重启服务或改变调度。采样历史保留 24 小时，定时分批清理；可用率仅针对实际采集的成功/失败样本，缺失期间不补为成功。

### 对账口径

实际流量和倍率扣费读取现有入口日统计，选择日期只影响这些历史值；待补报、待结算和失败批次均为当前状态。中转逻辑落地不重复记用户扣费。Agent 离线或版本旧时待补报量为未知，不将其当零。

网卡计数、代理实际流量和倍率扣费不是同一口径。本版未建立全新的历史网卡账本，页面不将机器当前累计量与所选历史日期强行相减。已有原始批次保留、清理和自动重试策略继续使用。

### 证书管理

只返回公开元数据，接口和拓扑不返回私钥、DNS 凭据或完整核心配置。续期请求以编号下发，节点先落盘登记，重启不重复执行旧请求；中断时标记失败，管理员可重新发起。五分钟内限制重复续期请求，结果由 Agent 实际回报决定，提交请求不等于续期成功。

自动续期仍由原 ACME 管理器执行。失败保留当前证书，成功后更新材料并应用到核心；界面区分当前材料和运行中是否已生效。

### 套餐临时限速

规则写入套餐，用户购买、续费、套餐变更或管理员勾选同步时复制到用户快照；未同步的已有用户保留原规则。Agent 按实际新采样判定，持续模式处理每个低速样本，窗口模式每秒最多计数一次；重复用户同步不重复消费旧速度，规则指纹只在规则变化时计算。统计的是用户在单个节点上的速度；跨节点不汇总判定。

持续超阈或窗口中累计超阈秒数达到条件后，执行临时上限与当前正常上限中的较小值，原地更新限速器使已有连接生效。不会因临时限速提高正常上限或改变计费。到期恢复当时正常上限；规则变化、取消规则和删除用户会清理旧状态。

进行中的临时状态以 0600 文件保存到实例目录，沿用隐私加密；重启按原到期时间恢复，不延长。文件损坏保留原文件并上报状态错误，内存判定继续，无法恢复的旧处罚不能保证继续执行。
