# YZboard 2.16.8 与管理端 0.98.5 发布

维护者：P0me1oo。日期：2026-11-15（北京时间）。

[面板 v2.16.8](https://github.com/P0me1oo/YZboard/releases/tag/v2.16.8) 和[管理端 v0.98.5](https://github.com/P0me1oo/YZboard-Dash/releases/tag/v0.98.5) 已正式发布并设为 Latest。面板公开、管理端私有的可见性保持。本次未更新生产服务器或发布 Docker 镜像。

## 固定来源与范围

面板固定源码为 `fb005c0c9eb5c971d4db34a2ff5a56d47adc237d`，管理端固定源码为 `3237173c8527c413593d1a71ac7b113ac1f00aee`，对应两个已推送的版本 Tag。

正式版本同时纳入此前 2.16.7、0.98.4 已推送的设备与 DNS 争锁修复、到期排序及用户流量布局。无需数据库迁移、依赖更新或 Agent 升级。
