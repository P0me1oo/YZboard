# 路由管理

路由管理定义“哪些流量做什么处理”，再选择要用这条路由的节点。节点程序（YZ-Agent）把路由翻译成 Xray 或 sing-box 的规则执行。

## 匹配条件

一条路由可以同时设置以下条件：

| 条件 | 说明 |
| --- | --- |
| 匹配值 | 每行一个域名或 IP 网段，例如 `example.com`、`1.1.1.0/24`，任一命中即可 |
| 协议 | 目前只有 BitTorrent，由节点内核识别 |
| 目标端口 | 单个端口或范围，逗号分隔，例如 `25,465,6881-6889` |
| 网络类型 | 不限、仅 TCP 或仅 UDP |

- 填了几种条件，就要几种条件同时满足才命中；同一种条件里的多个值，任一个对上即可。例如“目标端口 25 + 仅 TCP + 拦截”只拦截 TCP 的 25 端口，其他连接正常。
- 至少填写一种条件。只填协议、端口或网络类型而不填匹配值时，对所有目标地址生效。
- 已有路由升级后没有这些新条件，匹配结果不变。

## BitTorrent 识别

- BT 使用内核自带的协议识别，不靠关键词或固定端口：Xray 识别 TCP 握手和 uTP 建连包，sing-box 另外识别 UDP Tracker。两种内核都识别不了加密的 BT 连接和 DHT。
- 只有绑定了 BT 路由的节点才开启识别。开启后，由服务器先发数据的连接（例如邮件）建立时最多多等约 0.2 秒（Xray）或 0.3 秒（sing-box）；普通网页、视频等由客户端先发数据的连接不受影响。
- 中转入口节点绑定的路由作用于入口自身的用户；经入口转往落地的流量，按落地（逻辑节点）自己绑定的路由处理。

## 选择节点

- 创建或编辑路由时可以多选节点，也可以一键全选或清空。保存时，新选中的节点加上这条路由，取消选中的节点去掉这条路由，节点上绑定的其他路由不受影响。
- 节点编辑页原有的路由多选继续可用，两边改的是同一份绑定关系。
- 删除路由时，这条路由会同时从所有节点上移除。
- 修改后，面板立即向在线节点推送新配置（包括隐藏但仍在运行的节点），其他节点在下次拉取配置时生效。

## 新增节点默认应用

- 路由上的“新增节点默认应用”开关打开后，新建节点时会预先选中这条路由，保存前可以去掉。新建路由时默认开启，可以手动关闭；已有路由升级后保持关闭。
- 通过接口新建节点而没有提交路由时，面板自动套用这些路由；提交了路由列表（包括空列表）时以提交值为准。
- 编辑已有节点、复制节点都不套用默认路由，复制节点沿用原节点的路由。

## DNS 动作

节点程序目前没有真正实现 DNS 动作：Xray 节点会直接拦截命中的域名，sing-box 节点上命中的连接会失败。管理端新建路由时不再提供 DNS 选项；已有的 DNS 路由原样保留，编辑时仍可保存。DNS 动作不能使用协议、端口或网络类型条件。

## 版本要求

需要面板 `1.26.0`、Node `v1.22.0` 和管理端 `0.9.0`。旧 Node 不认识新条件：只填新条件的路由会被整条跳过；同时填了匹配值的路由会被当成只按匹配值处理，范围变大。先升级全部 Node，再使用新条件。
