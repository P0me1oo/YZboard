# YZ-Agent 一键安装

适用面板版本：`1.15.4`。发布来源、镜像及回滚记录见 [兼容矩阵](../YZ_COMPATIBILITY.md)。

## 安装入口

服务器管理中新建服务器后返回的安装命令，以及已有服务器的“安装命令”，均由 `MachineController::buildInstallCommand` 生成。安装器地址统一为：

```text
https://github.com/P0me1oo/YZ-Agent/releases/latest/download/install.sh
```

命令保留机器模式、实际面板地址、机器凭据、机器编号和 `latest` 版本参数。面板不强制指定内核，继续由安装器区分新绑定与已有实例。复制和执行命令仍沿用现有页面流程。

管理页面在加载语言包后、初始化管理端前，将服务器管理中的旧程序名替换为 `YZ-Agent`，覆盖中文、英文和俄文的安装标题、安装说明、启用说明及认证提示。转换使用本次页面模板，语言包缓存不会保留旧显示名称；固定上游管理端子模块及其引用保持原版本。

## 兼容性

本版基于面板 `v1.15.3`，配套 YZ-Agent `v1.14.0`。旧 `YZboard-Node` 安装器地址目前通过 GitHub 重定向仍可获取新版；旧命令可用不代表面板的名称更新已经完成，本版将页面和直接下载地址一起补齐。

已有机器的编号、凭据、配置及通信格式保持原约定，更新面板不要求重新创建服务器或重新绑定节点。已安装节点按 [YZ-Agent v1.14.0 发布说明](https://github.com/P0me1oo/YZ-Agent/releases/tag/v1.14.0) 升级；一键安装按钮用于安装和绑定，不替代已有节点的常规升级。

发布顺序为已发布的 YZ-Agent `v1.14.0`、面板 `v1.15.4`。本次不修改两个核心，也没有数据库迁移。

## 验证

本地 PHP `8.4.21` 配合内存 SQLite 完整回归 192 项测试、2889 个断言通过，包括一键命令的实际生成结果；管理端原有 72 项测试通过。通过 Laravel 渲染实际管理页面后，使用固定上游的三份语言包验证 15 处名称、模块加载顺序、旧语言包缓存、重复初始化及缺失语言包的处理，其他翻译保持原值。PHP 语法与 Git 空白检查通过。

正式镜像还需核对两个架构内的控制器、页面模板与版本文件，结果记录于兼容矩阵。所有检查使用本地环境或发布 CI，不连接真实节点服务器。
