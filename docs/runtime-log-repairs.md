# 运行日志修复

维护者：P0me1oo。日期：2026-11-10。

## WebSocket 握手

握手升级前不能通过 WebSocket 编码发送拒绝正文。Workerman 会暂存此类正文，连接提前关闭后 Nginx 只能返回 502。现在握手拒绝使用原始 HTTP：缺失或无效凭据返回 401，停用或不可用身份返回 403，错误身份参数及无效握手返回 400，不支持的升级或协议版本返回 426。依赖异常返回 503，并保留脱敏故障诊断，不使整个 WebSocket 工作进程退出。

管理端仍先升级，再通过消息提交一次性票据；已建立连接的认证撤销与认证超时保持原语义。握手拒绝记录只含固定原因和状态码，不保存 URL 查询、令牌或原始请求头。正常续期的 412 表示需要补发完整快照，使用调试级别；完整同步和其他请求失败保持警告。

## 数据库连接清理

生产工作进程达到请求数上限后会正常回收。新增 Octane `WorkerStopping` 监听器，从根应用释放已经解析的数据库连接，包括读连接和写连接；没有使用数据库的工作进程不会在退出时初始化数据库。异常通过独立错误出口记录类型，防止应用日志读取策略时重新打开数据库连接。

## Nginx 日志权限

Solid-US LA 的 Nginx 工作账户为 `www-data`。站点日志目录采用 `root:www-data / 0750`，日志文件采用 `www-data:adm / 0640`；全局日志轮转的 `create` 用户同样应为 `www-data`。仅修正已配置的日志路径，保留日志内容和现有保留策略。修改后检查配置，再让 Nginx 重新打开日志并检查新增权限错误。

## 配套节点

Agent v2.36.2 在准入请求可能更改面板快照时使旧续期基线失效，并防止迟到同步确认重新激活旧基线。未升级节点仍会按原协议在 412 后补发完整快照，面板更新不能代替节点修复。订阅聚合插件不在此次修复范围内。
