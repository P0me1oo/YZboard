# 节点内部端口检查

适用面板版本：`1.13.5`。正式来源与镜像核验记录见 [兼容矩阵](../YZ_COMPATIBILITY.md)。

## 检查规则

检查目标是防止同一绑定服务器上的节点争用内部监听端口。当前面板向 Node 下发的监听地址为 `0.0.0.0`，因此按“绑定服务器 + 内部端口 + TCP/UDP”比较。

- 两个节点的内部端口相同，且 TCP/UDP 监听范围有交集时，提示冲突节点名称、编号和端口，并拒绝保存。
- 一个只监听 TCP、另一个只监听 UDP 时，可以使用相同的端口号。
- 客户端连接端口不参与重复检查；同一个节点的连接端口和内部端口可以相同。
- 不同绑定服务器互不影响；未绑定服务器的节点不参与机器内的重复检查。
- 隐藏或停用节点仍保留配置中的内部端口，避免重新启用时才发现重复。这是面板配置的保留规则，不表示停用节点正在监听。
- 内部端口必须是 `1–65535` 的整数，不接受端口范围或列表。Hysteria2 的跳跃范围仍填写在连接端口中。

## 传输方式

判断的是固定内部端口上的监听方式，不是节点能否代理 UDP 流量。

| 节点配置 | 固定内部端口 |
| --- | --- |
| Shadowsocks、Naive | TCP 和 UDP |
| Hysteria、Hysteria2、TUIC | UDP |
| Mieru | 按所选 TCP 或 UDP 判断 |
| SOCKS / Xray，包括历史空内核值 | TCP 和 UDP |
| SOCKS / sing-box | TCP；UDP 转发使用临时端口 |
| VMess、VLESS、Trojan 使用 KCP、mKCP、QUIC 或 Hysteria 传输 | UDP |
| VMess、VLESS、Trojan 使用 TCP、RAW、WebSocket、gRPC、HTTPUpgrade、XHTTP 等传输 | TCP |
| AnyTLS、普通 HTTP | TCP |

Xray 的 HTTP 入站开启 TLS 时，按实际生成的传输设置判断。Naive 的默认配置同时启用 HTTP/2 与 HTTP/3，因此预留 TCP 和 UDP；协议能否在所选内核中启动，仍受该内核已有能力和证书配置约束。

规则依据为 Node 两个内核的配置生成器，以及当前固定的 Xray `b4caa82d6414196565599c19ebc1b53e331349b6`、sing-box `v1.14.0-yz.2`。本次没有修改 Node 或核心依赖。

## 表单与复制

填写内部端口，或改变服务器、协议传输方式、内核时，表单等待输入停顿约 300 毫秒后检查，在内部端口字段旁显示结果。关闭表单或改变输入后，旧请求的返回结果不会覆盖当前状态。检查失败时可以修改输入或重试，保存接口还会重新检查数据库中的最新占用。

复制接口保留两个端口和绑定服务器，不为副本自动分配新端口；从面板 `1.20.4` 起副本默认关闭并隐藏，不再沿用源节点的启用状态。这样避免副本刚建好就以相同的机器和内部端口下发给 Node。源节点开关为空（独立部署）时副本保持空值，只强制隐藏。复制后的节点可以继续修改名称、倍率等无关字段，已有重复配置不会被批量改写。修改内部端口、绑定服务器或监听传输范围时重新检查；停用后重新启用也需要通过检查，所以副本必须先换到可用端口才能开启。

复制得到相同配置不代表两个独立节点可以同时监听相同端口。需要让副本独立运行时，应先为它分配可用的内部端口，或绑定另一台服务器，然后再开启并取消隐藏。

列表中的绑定、内核切换、重新启用以及批量操作沿用相同规则。批量操作中任一节点冲突，整批数据库变更回滚，不留下部分节点已经换绑的结果。

## 实现与验证范围

- `ServerPortService` 提供统一判断，正式保存使用数据库事务、机器行锁和当前读取；复制不经过此校验，副本默认关闭，改端口并开启时才校验。
- 管理端表单检查由 YZboard-Dash 源码工程实现，随管理端产物一起发布；产物内含该定制的校验在面板 `tests/admin-dist.test.cjs` 中执行。
- 自动测试覆盖同端口 TCP/UDP 共存、双传输冲突、内核差异、复制后编辑、错误恢复、批量回滚、过期响应和构建补丁完整性。
- 本地 PHP `8.4.21` 完整回归 176 项、2289 个断言及管理端 33 项测试通过。Chrome 独立实例配合模拟接口验证实际弹窗中的字段提示、保存拦截、TCP/UDP 同号共存和复制后编辑，没有 JavaScript 异常；本次临时浏览器和模拟服务已关闭。
- 本地数据库验证使用内存 SQLite；未验证 MySQL 多连接并发，也未进行真实服务器的监听测试。

检查仅覆盖面板管理的节点内部端口，不扫描服务器上的其他程序、手工监听或防火墙转发规则。Hysteria2 跳跃端口集合的外部转发冲突仍由现有 Node 防火墙逻辑处理。
