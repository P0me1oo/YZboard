# YZboard 2.15.0 与管理端 0.97.1 发布

维护者：P0me1oo。日期：2026-11-10。

[面板 v2.15.0](https://github.com/P0me1oo/YZboard/releases/tag/v2.15.0) 与[管理端 v0.97.1](https://github.com/P0me1oo/YZboard-Dash/releases/tag/v0.97.1) 已发布并设为 Latest，面板公开、管理端私有的访问范围保持。Solid-US LA 已完成生产部署，见[部署记录](deployment-2.15.0.md)。

## 范围和来源

本次包括此前所有未发布应用改动：2.13.0–2.13.3 的链路健康全局设置、PowerDNS 请求容错、错误日志及运行修复，同时包含 2.14.0 自动解绑。此前生产 2.12.2–2.12.5 已部署的 HTTP 实时状态修补、PowerDNS、日志、WebSocket 握手和进程退出清理，已逐文件确认包含在本版；并非这些修复首次上线。

面板固定源码 `09a72b9c3b401c2e54c93328a1c5b7a27c91e27c`。管理端固定源码 `24ece976141f0c18c906417196418ddef4b560e0`，产品构建来源 `adf1c97bcae38227c00885b8ce9643ce6c42442d`；两者只相差两个测试文件的参考差异断言与异步校验等待，产品和构建逐字节相同。274 份管理资源已集成并核对，未直接编辑产物。

## 验证

- PHP 8.4.27、SQLite 完整 1,805 项、33,661 断言通过，12 项 MariaDB 专项按条件跳过。
- MariaDB 11.4.8 与生产同版 12.3.3 均开启严格分组和快照隔离，各完整 1,805 项、33,679 断言通过，无跳过；使用独立 Redis 8.0.2。
- Node 24.22.1：3,121 份源码检查、159 项行为、正式构建、资源、开发模式检查通过；面板五项资源契约通过。
- 441 个浏览器场景首轮 439 项通过。旧参考不含新增健康设置，补充明确区块断言后 29 路由对照通过；倍率用例在异步校验完成前修改下一项造成偶发提前保存，改为等待具体校验提示，整组四项连续三轮共 12 项通过。全部场景有通过结果，未将首轮报告为全部成功。
- 临时浏览器最初缺少中文字库，补齐后健康全局设置、桌面/手机与中英俄文五项复验通过并检查截图；没有改动产品字体资源。
- 本机锁定依赖安装、构建集成、来源核验完成；GitHub Actions 仍因账号账单锁定未执行，未当成通过。

两仓库各提供安装包、发布清单和 SHA256SUMS，共六份附件均重新下载并与本地包匹配。面板以匿名公开下载核验，私有管理端通过已授权 GitHub 下载核验；源码包含 composer.lock，不含真实环境配置或本地规则，管理端包不含源码映射。完整摘要见[核验记录](release-2.15.0-verification.json)。

配套 Agent v2.37.0 已在此前独立发布，本次没有更新运行节点或发布镜像。版本标签与安装包固定不动，发布后文档单独提交。
