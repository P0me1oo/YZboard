# YZboard 2.18.1 与管理端 0.100.0 发布

维护者：P0me1oo。日期：2026-11-16（北京时间）。

[面板 v2.18.1](https://github.com/P0me1oo/YZboard/releases/tag/v2.18.1) 和[管理端 v0.100.0](https://github.com/P0me1oo/YZboard-Dash/releases/tag/v0.100.0) 已正式发布并设为 Latest。面板保持公开，管理端保持私有。本次未部署生产服务器、发布 Docker 镜像或升级 Agent。

## 固定来源与范围

面板源码固定为 `3c3b2dfe28d0f3012f22c51d1e3c0e67401da45a`，管理端源码固定为 `bdf17c2bfa66c097adec77b4698e0411e4c80bf0`；两个版本 Tag 均指向已推送的对应程序提交。后补发布记录不移动 Tag 或替换附件。

统一 Reality 更换 SNI 时，同域名回源按每个节点的旧 SNI 联动，保留回源中的实际端口。节点批量统一的两种方式、前置池自动统一及同步均适用；独立回源继续保留，同域名回源更新后再检查防盗用冲突，任何校验或写入失败整批回滚。详见[Reality 参数统一](node-reality-unify.md)。

本次同时交付此前未发布的节点公网地址自动填充、类型按数量排序和常见运行报错中文说明，包含对应文档与运营商 DNS 已完成启用记录。面板内置管理端 0.100.0，无数据库迁移、依赖、Agent 或核心变更。

## 验证

PHP 8.4.27、PHPUnit 11.5.57、Redis 8.0.2、PHP Redis 6.2.0；MariaDB 11.8.6 启用 `ONLY_FULL_GROUP_BY`。

- SQLite 完整 1,926 项测试、35,673 条断言通过，12 项数据库专用检查按条件跳过。
- MariaDB 完整 1,926 项测试、35,689 条断言全部通过，无跳过。
- 管理端 3,125 份源码检查、171 项行为测试、构建资源和面板 5 项资源契约通过。六份待发布业务源码与已有构建映射一致，274 份集成资源和 125 份 gzip 副本一致；复用同一源码已通过的 29 项相关浏览器检查。
