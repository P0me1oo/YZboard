## 修改

前置池允许加入开启 PROXY 协议接收的节点，保留原接收状态。节点连接地址仍决定用户的实际入口，入口前使用 Realm 等转发机时仍可保留其 PROXY 头。

入口域名自动使用所选 DNS 配置的完整基础域名，只输入池前缀；例如 `pool` 与 `example.com` 组成 `pool.example.com`。编辑、切换 DNS 配置及保存失败保留前缀，已有直接使用基础域名的池原样保存。
