# 节点域名与 DDNS

系统设置集中维护 DNS 预设、记录用量和旧解析清理。新增配置默认使用 PowerDNS，也保留 Cloudflare 以兼容已有节点和旧转发池。前置 DNS 池的四级域名、故障剔除和 NS 委托见[前置 DNS 调度](load-balancer.md)。

## 独立开关

普通节点的“启用 DDNS”“用户独立域名”和“跟随用户状态”分别保存，新绑定默认关闭：

- DDNS 负责手填连接 IP 改变后的基础 A/AAAA 同步；不读取机器 IP 自动覆盖普通节点的手填地址，不自动启用用户独立域名或状态跟随。
- 独立域名关闭而 DDNS 开启时，共用该节点的基础域名；独立域名开启时为每名获授权用户生成固定随机标识的 CNAME。独立域名可以在 DDNS 关闭时使用，基础 IP 保留首次配置或最后同步值。
- 跟随用户状态需要显式开启，才按封禁、流量耗尽和自然到期撤销个人解析；恢复后复用原随机标识。权限组和节点启用状态仍决定入口授权，域名开关不会改变代理账号认证。

例如预设 `example.com`、节点前缀 `hk01`：基础域名为 `hk01.example.com`，个人域名为 `随机标识.hk01.example.com`。已有更深的节点前缀和个人域名继续兼容；前置 DNS 池明确限定使用三级池域名，生成用户四级域名。

开启任一节点域名开关时，连接地址需要有效 IPv4 或 IPv6，并选择预设及唯一前缀。TLS 或 Reality 必须明确填写证书或握手域名，订阅仅替换连接域名，不改写 SNI、密钥或内部落地地址。中转节点沿用实际前置入口的配置；复制节点不继承 DNS 绑定和托管记录。

TTL 可配置为 30–86400 秒，默认 60 秒。PowerDNS 使用配置值，Cloudflare 受其服务限制最低按 60 秒。DNS 与客户端缓存不会因记录改变而立即清空，现有连接也不会被 DNS 更新迁移。

## 同步与归属

节点地址、用户状态及授权变化后排队同步，每分钟 `ddns:sync` 补偿自然到期、批量写入和外部接口错误。同步按最新数据库状态计算，不在队列中携带旧 IP；共同锁与轮转游标避免重复处理和错误配置长期阻塞其他入口。基础值或所需记录变化会同步，无变化时每十分钟核对远端记录。

PowerDNS 通过 API 更新整组记录并使用随机 comments 标记归属；API Key 加密保存且不回显。用户记录仅保存在 PowerDNS，不查询或消耗 Cloudflare 用户记录额度。区域自己的 NS/SOA 不受清理影响。Cloudflare 保留原分页、批量写入、容量检查及限流退避。两种服务都不覆盖非本功能创建的记录，也不通过泛解析替代个人域名。

未完成准备的个人域名不会进入订阅，接口返回可重试的准备状态。同步失败保留已确认的记录归属，下次继续核对。外部错误响应、密钥和请求头不写入页面错误或日志。

## 关闭、切换与旧数据

普通节点关闭两个域名开关后恢复原节点地址，新用户不再创建个人域名；已存在的基础记录和个人名称继续保留，基础 IP 不再跟随 DDNS 更新。显式开启的状态跟随仍可清理失效用户记录。需要撤销全部旧解析时，在系统设置中点击“清理解析”并确认；清理完成后才可删除其预设。不要在客户端仍使用旧名称时提前清理。

更换预设或前缀时旧绑定标记为退休，保留到明确清理，避免更新订阅前立即失效。前置 DNS 池有独立规则：关闭用户独立域名后撤销个人 CNAME，共用池域名；停用或全部前置故障时撤销该池的托管解析，均不受 DDNS 开关影响。

升级时，原来启用的旧 DDNS 显式保留其个人域名开关；旧绑定已有的状态跟随也显式保留，包括关闭后保留旧解析的绑定。新绑定的三个开关各自默认关闭。旧 Cloudflare 绑定不会自动迁移到 PowerDNS，需先准备区域和 NS 委托，再按旧解析保留及清理流程切换。
