# 管理端外观设置

从“系统设置 → 外观设置”调整管理侧边栏。默认显示全部模块，修改自动保存，成功后立即生效，刷新后保留。配置对所有管理员生效。

面板 `1.97.0` / 管理端 `0.68.0` 新增拖拽排序，当前为本地未发布版本。菜单按侧栏分组排列，宽屏子项采用双列，手机单列。使用菜单左侧的拖拽手柄调整同级顺序，也可以聚焦手柄后按方向键调整。

面板 `1.97.1` / 管理端 `0.68.1` 在页面入口携带经过清理的当前外观配置，刷新首屏直接显示已保存的顺序和显隐，避免接口返回前先显示默认菜单。未提供首屏配置的旧页面仍通过接口读取，读取失败可重试。已保存的自定义排序继续优先，点击“恢复默认顺序”采用当前默认顺序。

面板 `1.98.0` / 管理端 `0.69.0` 将原来的合并栏目拆为两个独立栏目，默认依次位于节点管理之后、用户管理之前：

| 栏目 | 默认子菜单顺序 |
| --- | --- |
| 套餐管理 | 套餐设置 → 订单管理 → 优惠券管理 → 礼品卡管理 |
| 订阅管理 | 订阅设置 → 订阅模板 → 客户端限制 → 订阅防护 |

两组可独立折叠、隐藏及排序。子菜单地址、隐藏选择和组内相对顺序保留；旧排序没有新套餐栏目时，将新栏目插在订阅栏目之前，其他自定义顺序保留。保存新栏目位置后，以显式保存的位置为准。整组隐藏仅作用于该栏目当前的子菜单，新套餐栏目默认显示；旧的订阅整组隐藏设置不再影响已移出的套餐入口。套餐页面的菜单显示为“套餐设置”，仍使用原地址 `/finance/plan`；其旧显隐与排序标识保留，新增套餐整组标识为 `plan-management-group`，不新增数据库迁移。

- 一级栏目均可排序：仪表盘、统计分析、系统管理、节点管理、套餐管理、订阅管理、用户管理；每组内的全部固定子菜单也可以排序，包括系统配置。子菜单保留所属栏目，不支持跨组移动。
- 隐藏菜单仍可排序，重新显示后沿用保存的顺序。“恢复默认顺序”仅清空排序，“全部显示”仅清空隐藏配置，两者互不影响。
- 系统管理、系统配置可以移动，但不能隐藏。访问记录与其他统计入口一样支持显示、隐藏和排序；插件动态注册的菜单仍不参与设置。
- 顺序通过现有配置接口保存为 `admin_sidebar_order`，仅接受已知入口组成的无重复列表。未设置顺序或读取失败时沿用默认顺序；以后新增的入口在同组已排序菜单后显示。

“外观设置”位于“站点设置”正下方，使用调色盘图标。此调整在面板 `1.76.1` / 管理端 `0.48.1` 开发完成，随面板 `1.77.0` / 管理端 `0.49.0` 正式发布。

- 可以隐藏整组（例如套餐管理、订阅管理），也可以单独隐藏套餐设置、客户端限制等入口。
- 隐藏整组会暂时禁用子项开关，保留子项原来的选择；重新开启该组后恢复这些选择。全部子项隐藏时，侧边栏不再显示空组。
- 系统管理和系统设置始终保留，确保可以进入外观设置恢复。点击“全部显示”清空隐藏配置。
- 保存期间禁用开关，失败保留原状态并提供重试。读取失败时不会保存默认值；侧边栏读取失败且没有缓存时显示全部入口。
- 这项设置只控制菜单显示，不改变访问权限、功能开关或后台任务。隐藏客户端限制入口不会停用既有规则；直接访问原页面地址仍可使用。插件动态注册的菜单不在本次设置范围内。

面板 `1.70.0` 配套管理端 `0.43.0`。通过原管理配置接口的 `appearance` 分组读取，使用 `admin_sidebar_hidden` 保存隐藏入口标识；服务端拒绝未知标识、重复标识、非列表值及受保护入口。配置使用现有设置存储，本功能无需新增数据库迁移或升级 Node、代理核心。
