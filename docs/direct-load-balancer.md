# 直出负载池

面板 2.21.0、管理端 0.103.0 起，负载分配支持“直出负载池”。一个统一订阅节点对应多台现有直连服务器，池线路的连接路径为“用户 → 分配的成员 → 互联网”。面板和 PowerDNS 负责管理及解析，不承载用户代理流量。

面板 2.23.0、管理端 0.105.0 起，成员节点可同时提供直出和中转。池只管理统一直出线路；落地绑定实际成员，继续使用原有中转订阅。比如用户甲只有池权限，经成员 A 直接出网；用户乙只有 A 的落地权限，经 A 转发到落地。拥有两类权限的用户可分别选择两类线路。

## 配置

1. 在“负载分配”打开“新建直出负载池”。选择 PowerDNS 配置，填写节点名称与池域名前缀。
2. 勾选不同服务器上的 VLESS Reality + TCP 节点，每台服务器一个成员。公网端口、流控、额外 VLESS 加密及 Reality 参数须兼容；可以使用现有的自动统一 Reality 功能。成员继续复用原监听和 NAT 内部端口，Agent 至少为 v2.25.0。
3. 设置统一权限组、直出倍率、订阅排序和是否展示。倍率范围 0–1000，可以填写小数；初始值跟随首个所选节点，保存后不随成员重排改变。
4. 配置权重、优先级、动态负载或在线 IP 数调度。入口端口检查可选开启，不要求测速落地；不提供基于“前置到落地”延迟的两种选择策略。
5. 保存并同步 DNS，等待个人域名准备完成，再让用户更新订阅。用户只看到池的统一线路，原成员线路在加入池期间从订阅中隐藏。

成员已有落地时可以直接加入池，也可在加入后将它选为落地的“前置入口”。选择的是实际成员节点，直出池的逻辑订阅节点不作为中转入口。落地订阅连接该成员原地址，池的 DNS 调度只分配直出线路。

2.23.0 起统一直出线路编号下发给全部成员，包括暂时没有落地的成员；客户端需要更新订阅，才能在成员切换或后续新增落地时继续选中直出。成员复用原监听，不额外创建监听端口。

DNS、运营商分流、流量额度、动态负载和在线来源 IP 调度沿用[负载分配](load-balancer.md)及[动态调度](front-dynamic-scheduling.md)的规则。默认按用户稳定分配，不保证实际带宽平均；调度修改 DNS，切换受递归解析与客户端缓存影响，已建立连接不能迁移。

## 权限、流量与运行

- 成员接收池直出与自己各落地权限组内的有效用户，按用户的线路权限分别授权。只有落地权限的用户不能使用池直出，只有池权限的用户不能使用落地。封禁、到期、流量耗尽及用户连接、设备和限速约束沿用原有节点准入流程；权限变化按成员完整用户列表同步。
- 直出扣费使用池倍率，中转跟随成员原入口倍率，或使用落地已经启用的独立倍率。接收报告时保存各线路倍率和统一直出编号，重试及后续调价不改变已接收批次。各成员按实际报告结算一次，不额外对逻辑订阅节点再次扣费；直出统计归属统一订阅线路，中转归属落地，服务器流量及机器配额仍归属实际服务器。
- 节点列表显示实际扣费倍率；成员加入直出池期间显示池倍率，移出后显示原节点的当前倍率。
- 原成员的权限、基础倍率、展示、内核、监听和协议设置保留；池在运行时提供权限和扣费倍率。自动统一 Reality 仍会修改所选成员的 Reality 参数，停用或删除池不恢复旧密钥。
- 停用池撤销托管 DNS 并撤销直出线路权限，保留成员自己的中转用户和线路，不把成员原直出订阅重新展示。没有中转的成员接收空用户列表；隐藏统一订阅节点仅改变展示，不等于停用服务。离线 Agent 恢复后读取最新权限。
- 移出成员或删除池后，该成员恢复按原节点权限、倍率和展示提供服务。删除先停用并清理 DNS，清理失败保留停用池、成员关联和记录归属，处理后重试。

直出成员不能同时属于其他负载池，也不能把自身改为绑定其他前置的落地节点；它可以作为自己落地的中转入口。已有池不能原地切换用途；需要另一种模式时新建池，按原模式清理旧引用和 DNS。所有成员不可用时撤销解析，恢复后继续使用原个人标签。入口端口检查不替代成员到落地的链路检查；落地故障或停用沿用原中转阻断规则，不影响仍获准的直出线路。

## 存储与回退

复用已有池用途、加密模板、成员关联及节点字段，没有新增数据库迁移。池保存一个不绑定机器的逻辑订阅节点，不为 Agent 新建监听或核心实例。统一线路在负载分配中编辑，拓扑以直出池关联实际成员展示。

回退到不支持直出池的面板前，先停用并删除直出池，确认托管 DNS 清理成功、成员恢复原配置，再恢复固定旧版本。不要保留直出池数据直接切回旧程序。

回退到 2.21.0–2.22.2 时，这些版本不支持成员混合使用及统一直出线路编号。应先删除直出池，保留成员原有落地并同步配置，再切换固定旧版本；相关用户恢复原成员直出订阅后需要更新订阅。
