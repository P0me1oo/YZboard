维护者：P0me1oo。日期：2026-11-26。面板 2.30.2 已部署至 Solid-US LA，46 台受理 Agent 通过面板升级为 v2.51.1；详见[部署记录](deployment-2.30.2.md)。

## 机器流量累计的并发冲突

生产 MariaDB 12.3.3 使用 REPEATABLE READ，并启用 innodb_snapshot_isolation。结算途中读取统计启用时间建立读取视图，随后机器心跳更新同一机器行，原机器累计量写入因版本不可见而报 1020。原子加法和重试不能避免此冲突。

批次取得锁后，根据已保存的归属快照计算实际有增量的机器，按编号逐主键加排他行锁，再进入用户、节点和机器统计；旧版 StatServerJob 同样在事务开头取锁。失败仍整批回滚，完成标记仍与统计共同提交，不改变历史归属、倍率、取整或重复上报语义。心跳仅在同一机器的短结算事务期间等待。

专项回归使用独立 MariaDB 12.3.3、真实心跳连接和快照隔离，覆盖批次与旧版统计、提交后心跳恢复、重复批次；原有并发、批量写入和机器流量统计回归同时运行。未连接生产数据库执行故障注入。

最终针对性 MariaDB 回归合计 91 项、1166 条断言通过，包含结算、心跳、机器额度、实时接口、Lite 与日志；另有 8 项既有 phpredis 读取契约用例因本机缺少扩展跳过，不计入通过数量。本次未改变对应缓存读取实现。PHP 语法与差异格式检查通过。

发布阶段完整 MariaDB 回归发现新增真实提交测试缺少类结束后的迁移状态重置，导致后续统计用例读到残留夹具。已沿用既有并发测试的清理方式修正，运行逻辑不变；保留未正式发布的 v2.30.1 标签，最终版本顺延为 2.30.2。

## Lite 错误诊断

接入层记录一次有界诊断，管理异常处理不再重复记录通用错误。分类包含配置、网络传输、HTTP、响应大小、JSON-RPC 和协议结构；保留错误编号、短原因及阶段时间。RPC 扩展数据、完整响应、网址及认证头不进入新增上下文。客户端提示和网络安全校验保持。

## 节点通信诊断

Agent 为请求生成随机编号，并在失败时记录 DNS、连接、TLS、发送、首字节及总时间，保留原异常链的取消、超时语义。没有新增独立日志出口，仍由调用方现有日志和隐私策略控制。响应体读取失败也包含阶段信息。

面板向携带合法编号的节点请求回报处理耗时；仅已认证节点的慢请求（至少一秒）或服务端失败记录关联诊断，按原日志限频执行，并核对机器隐私设置。正常请求不新增数据库查询；不采集请求正文、认证参数或客户端地址。该诊断需配套版本部署后才能用于线上关联，不能据此宣称当前通信超时已经修复。
