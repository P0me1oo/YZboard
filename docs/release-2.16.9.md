# YZboard 2.16.9 发布

维护者：P0me1oo。日期：2026-11-15（北京时间）。

[面板 v2.16.9](https://github.com/P0me1oo/YZboard/releases/tag/v2.16.9) 已正式发布并设为 Latest，Solid-US LA 已完成生产更新。面板保持公开，配套管理端沿用已发布的私有 v0.98.5；没有发布 Docker 镜像或升级 Agent。

## 固定来源与行为

面板源码固定为 `ba2d73bf08a492259d7dd5aab3a7e7b84783f482`，管理端来源为 `3237173c8527c413593d1a71ac7b113ac1f00aee`。版本 Tag 保持指向本次程序提交，后补发布及部署记录不移动 Tag 或替换附件。

精简设备资格查询，共用有容量限制的账号状态解码备忘，复用节点锁内已校验的快照，保留账号锁内权威读取、权限撤销、名额与乱序保护。快速重试的短暂锁竞争记录为调试日志，旧节点等待超时及 Agent 最终失败日志保留。详细实现、局部验证与隔离性能数据见[优化记录](device-coordination-optimization-20261115.md)。

本版同时包含 2.16.8 已发布的负载分配弹窗与布局修正，内置管理端 0.98.5。数据库结构、锁定依赖、设备协议、许可期限与同步频率不变。

两套完整回归只在本机独立测试环境执行，没有连接生产数据库或注入故障；任务临时实例结束后清理。[完整测试记录](release-2.16.9-tests.json)保留环境、结果和受影响源码摘要。没有将本机 MariaDB 11.8.6 结果称作 CI 的 11.4 环境结果。

[Actions 43686712288](https://github.com/P0me1oo/YZboard/actions/runs/43686712288) 因账号账单锁定未启动，执行步骤数为 0。没有将自动检查计为通过，发布依据为上述本机完整回归。
