# 2.7.1 发布记录

维护者：P0me1oo。日期：2026-11-08。

配套管理端 0.92.1，包含此前未发布的 Lite 监控接入、自动/手动绑定、批量导入、国旗、历史曲线、流量配额与重置规则，以及四项审查修复：公网地址过滤、并发缓存等待、操作成功后列表刷新失败的恢复、老挝国家代码排序。

## 发布范围

交付面板固定源码与 composer.lock、管理端静态资源及校验清单。面板已经集成管理端，无需另行替换前端目录。无需升级 YZ-Agent 或代理核心；未发布 Docker 镜像，未执行生产部署。

## 验证

- PHP 8.4.27 / SQLite：完整 1,685 项、32,519 条断言通过，跳过 10 项 MariaDB 专项。
- MariaDB 11.8.6（ONLY_FULL_GROUP_BY）与独立 Redis 8.0.2：完整 1,685 项、32,523 条断言通过，无跳过。
- 管理端：3,117 份源码检查、155 项行为测试、正式构建、资源检查与开发模式检查通过；浏览器完整检查首轮 409 项通过、8 项失败，8 项失败场景补验全部通过，合计 417 个不同场景均有通过结果；这不是一次完整命令全部通过。
- 274 份管理端资源与面板逐字节一致，面板 5 项资源契约通过。主脚本 `assets/admin-BjExTWFq.js`，SHA-256 `59c76d886e46eca3383af1f9b39a0142238a8b7528d5b3ed0f2e8f7197acbe35`。

初轮完整 PHP 回归因临时运行库未启用 iconv 扩展导致两步验证用例失败，补齐后两套完整回归通过。浏览器固定参考缺少已发布的拓扑与链路健康，以及本版 Lite 入口；新增明确断言后再比较原内容，29 路由对照单项已通过。旧流量页面和年度热力图断言补齐已发布的“对账”标签，仍精确核对全部标签及顺序；键盘导航按四个标签验证，对账请求交回其独立模拟接口。路由选择弹窗首次出现 Escape 等待超时，未修改实现或断言，原场景单独复跑通过。Reality 禁用入口测试等待菜单入场动画与聚焦完成再发送 Escape，保留关闭菜单断言，连续三次通过。以上测试修正未改变产品源码和发布产物。

测试只使用本机临时数据库、Redis 与模拟 Lite 响应；没有真实 Lite 或生产环境联调。

GitHub Actions 未执行测试：[面板工作流](https://github.com/P0me1oo/YZboard/actions/runs/42439847065)因账号账单锁定，测试步骤数为 0；[管理端工作流](https://github.com/P0me1oo/YZboard-Dash/actions/runs/42439843002)启动失败，未创建测试任务。发布采用本地验证结果，没有将远端启动失败表述为验证通过。

## 更新与回退

本版新增一项迁移，创建 Lite 连接和服务器绑定两张表。按原生 PHP 更新流程执行数据库迁移后启用程序；接入配置在“服务器管理 → 接入 Lite”填写。

面板可回退到已发布的 v2.6.1（内置管理端 0.91.1）。新增表可保留，回退程序不依赖它们；不要为回退删除 Lite 配置和绑定数据。Lite 接入不修改本地流量保护、用户扣费或代理统计。
