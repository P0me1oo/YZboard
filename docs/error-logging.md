# 错误日志覆盖

面板日志修复已于 2026-11-09 以 2.12.3 部署修补版更新至 Solid-US LA，基于生产 2.12.2，管理端保持 0.96.1，见[部署记录](deployment-2.12.3.md)。本地开发版本 2.13.1 及 Agent v2.36.1 尚未发布，Agent 修复尚未部署。两边分别修复自己的诊断路径，通信格式和核心依赖不变。

## 面板

已处理的工单回复/关闭、支付排序、优惠券生成、公告修改、用户资料与佣金转账、礼品卡状态、插件管理、程序更新和数据库维护异常进入系统日志。订阅防护、用户连接/IP 连接/速度快照、WebSocket 认证与消息、管理端实时快照故障也保留原因。原接口返回、回滚、关闭连接和降级处理不变。

显式接口异常或 HTTP 异常的 5xx 会记录；普通 HTTP 4xx 校验或业务拒绝不作为系统故障。节点 WebSocket 原有协议错误警告继续保留事件与状态码。管理操作审计只表示操作发生，不能替代这些错误记录。

新诊断只保留操作、可信数字编号、异常类型、脱敏原因、代码文件/行号和最多八层不含参数的调用位置。数据库异常不记录 SQL、绑定参数或可能包含字段值的错误正文，只保留 SQLSTATE 和驱动错误码。每个进程按操作、异常类型和节点/机器编号每分钟最多输出一次，最多保留 256 个限频键；不同节点不互相覆盖。

异常明细保存在 Laravel 日志文件的结构化上下文中；管理端现有系统日志列表仍显示摘要，不展示完整上下文。本次没有改变管理端页面或日志查询接口。

系统日志出口写入失败不再覆盖业务响应，通过 PHP 错误输出限频记录出口故障。日志策略读取失败仍不恢复业务日志；仅此前已确认开启的处理器输出固定故障阶段和异常类型。明确关闭或从未成功取得策略的处理器保持静默。独立诊断通常在 PHP 服务标准错误或系统日志中，不一定出现在面板系统日志页面。

## Agent

机器控制轮询失败、日志握手/保存/上传失败、上传超时、证书续期及其记录读写失败、临时限速状态读写失败均有脱敏诊断。中转流量、在线来源及连接快照采样失败由调试级别提升为警告，保留一分钟限频；成功后再次失败立即记录。

日志上传器自身的故障仅输出本地，避免进入自己的队列造成递归。未确认批次继续重试；缓存损坏时不覆盖原文件，等待日志策略允许后才输出恢复失败。普通日志输出文件写入失败时，独立标准错误只记录故障类型，不复制原始日志或文件路径。

启动失败可能发生在正常握手之前。此时仅在失败路径使用最多五秒确认各活动身份的日志策略，全部允许后记录脱敏原因；多身份中任一身份停用、策略未知或面板无法确认时仍保持静默。隐私保护不会被错误日志绕过，也不会补录关闭期间的记录。

这些修改补齐已确认的盲区，不保证无损保存所有错误：日志级别、关闭开关、隐私策略、队列容量和进程被强制终止等限制仍然适用。
