# 节点地区分类与批量排序

适用版本：面板 `1.59.1`、管理端 `0.34.1`。本功能在 `1.59.0` / `0.34.0` 开发阶段完成，本次合并交付；Node 沿用 `v2.9.0`。

自面板 `1.61.0`、管理端 `0.36.0` 起，筛选显示名称由“国家/地区”缩短为“地区”，三种语言同步更新，分类规则和原有多选行为保持不变。

## 节点用量与承载量（1.77.0，已发布）

配套管理端 `0.49.0`，节点列表同时显示“节点用量”和“承载量 / 上限”。节点用量是升级后按实际线路累计的原始上传加下载：入口只计直出，中转记到落地，不乘倍率。承载量继续包含入口转发并使用原上限；“重置流量”只重置原承载量，不清空新用量或历史统计。

服务器管理另行显示“服务器代理流量”，同机中转只计一次。两类统计的示例、旧记录和保留范围见[统计分析](statistics.md)。

## 地区

节点管理上方的“地区”筛选可以多选，并与名称、协议、内核、服务器、权限组筛选一起使用。选项只列出当前节点名称识别到的国家或地区，无法识别的统一显示为“未识别”。更改筛选后回到第一页。

分类复用服务器名称识别表，支持表内的中英文国家或地区名称、城市、常用大写缩写和已有国旗字符。例如“香港 01”“Hong Kong”“HK01”归为香港，“Tokyo”归为日本。英文名称不区分大小写，缩写按大写匹配。修改节点名称并刷新列表后重新分类。

面板 `1.99.1` / 管理端 `0.70.1` 的本地版本将词表补齐到 257 个国家和地区，并与订阅国旗共用同一来源。“格陵兰”“Greenland”“GL01”和已有格陵兰国旗均归入格陵兰；服务器排序中格陵兰归入美洲。来源与范围见[词表维护](../../YZboard-Dash/docs/country-aliases.md)，本次尚未发布。

同一名称包含多个地区时，取最先出现的具体国家或地区；同一位置优先匹配更长名称，例如“中国香港”归为香港。“中国电信”“中国移动”“中国联通”和“CN2”不作为所在地依据。仅写“亚洲”“欧洲”等泛称或未收录写法时归为“未识别”。分类用于管理端筛选，不写入节点配置，也不依据 IP 推断所在地。

## 服务器自动排序（1.111.1，已发布）

在“系统设置 → 节点配置”开启“服务器自动排序”，默认关闭。开关控制节点管理列表及其订阅顺序，服务器管理列表沿用原有的名称地区显示排序。

- 只对开启后创建的新节点生效；升级前已有、开启前创建的节点均保持原排序，开启动作不遍历或重排历史节点。
- 新节点首次有效上报且名称能识别出具体国家/地区时，移到相同权限组集合、相同国家/地区的最后一台后面；其他节点的相对顺序不变。多权限组的编号顺序和数字/字符串写法不影响匹配，集合不同则不匹配。
- 未分配权限组视为一个独立集合；全部未分组时也会按国家/地区归位。没有匹配节点时保持创建位置，不另行按地区全局重排。
- 地区沿用上文的名称识别，不新增 IP 查询。暂未识别时保持原位，等待后续有效上报；识别成功后只处理一次，即使无匹配也不再自动移动。
- 关闭期间上报的待排序节点取消资格，重新开启后不会补排。配置读取、用户列表拉取和握手不触发排序；HTTP 上报及实时 HTTP/WebSocket 状态使用同一排序逻辑。
- 重复上报、节点重启和重新连接不会再次排序；自动归位后管理员仍可手动调整。排序位置与一次性标记在同一数据库事务保存，失败整体回滚，后续有效上报可重试。

配套管理端 `0.81.0`，一并交付 `1.109.0` / `0.80.0` 开发阶段的自动排序，Agent 和核心无需修改。新增迁移为节点保存待排序标记，历史数据默认不参与；前置池内部运行节点不参与管理列表自动排序。

## 批量排序

1. 点击“编辑排序”，勾选需要调整的节点。
2. 页面底部居中显示已选数量，以及“移至顶部”“上移一位”“下移一位”“移至底部”四个按钮。
3. 调整完成后点击“保存排序”。关闭操作栏只清空选择，已调整的草稿仍保留。

所选节点保持原有先后关系；连续选中的节点一起移动，间隔选中的节点各向对应方向移动一位。到达首尾或选中全部可见节点时，对应按钮禁用。无选中节点时操作栏隐藏。手机端可进入排序、选择单个节点或全选，并使用相同操作栏。

批量移动以当前筛选结果为范围：只交换可见节点占用的位置，隐藏节点的位置保持不变，隐藏的已选节点不计入操作栏。清除筛选后可以检查完整顺序。保存仍通过原有排序接口提交所有节点的顺序。

进入排序模式会清除临时列头排序，避免覆盖手工调整；原单节点拖拽继续可用。保存期间禁止重复提交和继续移动。保存或随后刷新失败时保留排序草稿与选择，可直接重试；成功后退出排序并恢复正常分页。离开页面或直接刷新页面会丢弃尚未保存的草稿。

## 交付范围

面板 `1.99.2` / 管理端 `0.70.2` 起，点击节点编辑中的“高级设置”默认选中第一项“连接设置”。其他页签仍可切换，MUX 和路由标记继续直接打开对应页签。此版本本地未发布。

面板 `1.76.1` / 管理端 `0.48.1` 起，节点操作菜单按“编辑、复制、重置流量、删除、隐藏／显示”排列。隐藏和显示保持原有功能，桌面与手机使用相同顺序。

地区分类与批量排序在 `YZboard-Dash` 源码实现，构建后集成到面板；服务器自动排序由面板处理有效上报，并新增待排序标记迁移。节点通信和核心保持原有格式。管理端本地模拟测试不代表真实生产环境联调。
