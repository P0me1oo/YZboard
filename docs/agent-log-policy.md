# 隐私保护模式

Agent `v2.39.0` 起隐私保护改为加密记录，沿用原有开关和按机器派生的文件密钥，无需新增迁移或重建机器。本地候选面板 `2.23.0`、Agent `v2.40.0` 优化运行日志保存和上传，尚未发布或部署。

在“服务器管理”新建或编辑机器，调整“隐私保护模式”并保存。可以先下发配置、运行 Agent 后再开启，也可以提前开启后安装。保存后仍可关闭或再次开启；已开启的旧设置继续沿用，不自动关闭。

开启后，Agent、节点和 Xray / sing-box 的运行日志继续产生，逐条加密保存到节点本地 `runtime.log.enc`，不写入终端、标准错误或系统服务日志。日志文件每份最多 20 MiB，保留三份轮转文件，权限为 `0600`。原有明文历史不自动删除；新加密运行日志关闭模式后仍保持密文。

面板正常接收运行日志，继续按“Agent 日志”的开关和期限记录警告、错误、致命错误及 Xray 崩溃事件，通知沿用原有开关和防重。路由拦截记录也正常入库，使用独立保存天数，不受通用日志开关控制。隐私开关控制节点本地保护，不覆盖面板各类日志的记录规则。

候选面板 2.23.0 在原握手能力中声明最低上传等级为警告，Agent v2.40.0 在脱敏和入队前筛选普通信息、调试日志；节点本地仍按原等级加密记录。旧 Agent 忽略新增字段，旧面板未声明或返回未知等级时新 Agent 沿用原上传范围。加密日志格式、机器密钥、面板入库及通知规则保持，缓存和句柄优化见[验证说明](../../YZ-Agent/docs/log-performance-optimization.md)。

首次取得明确策略前保持静默，取得密钥后才允许隐私身份记录和上报。握手、机器发现和控制回报均可切换出口；重载及重启重新领取机器密钥。加密缓存保留原批次编号，网络故障后重试，不能回退到明文缓存或输出。

同一进程按实例隔离已归属日志；共享 Xray 日志只有单一可信身份时上报面板。多个身份共用进程时，共享日志只写到配置顺序中首个已确认隐私身份的本地密文文件，不复制到各面板或推测节点归属。不同机器仍不能共用敏感数据目录；旧式多节点绑定需要属于同一机器，需要不同策略的机器应使用独立实例。

这项设置不停止流量计费、在线状态、设备限制或代理访问记录，也不影响面板自身的系统、登录和管理审计记录。版本、状态等主动查询和操作系统的服务管理记录不属于 Agent 运行日志。设置不会隐藏程序身份，也不能阻止服务器管理员检查配置、内存或下发的用户列表。

Agent `v2.27.0` 使用原有认证身份向面板领取按机器派生的 AES-256-GCM 文件密钥。密钥仅在节点内存中保存；敏感配置、程序管理的证书、待确认流量和缓存加密落盘，重启后自动领取密钥恢复。启动所需的面板入口、身份、凭据引用及必要运维信息仍可读，`credentials.env` 继续由服务管理器读取。各实例独立恢复，冷启动需要面板可达；密钥领取失败时保留文件并自动重试，不降级为明文。

关闭后，Agent 自动解密受管理目录中的已有加密文件、实例配置及可确认身份的配置备份，后续恢复明文保存，文件权限仍为 `0600`。转换与运行中的文件写入互斥，保留流量、重试编号和扩展配置；重复开关不会重复累计。解密失败保留未完成文件及配置恢复信息，并自动重试。密钥接口在关闭后仍向已认证的原机器提供原密钥，因此先关闭再整机重启也能完成恢复；整机自动启动还需 Agent 服务已启用开机自启。独立格式的加密运行日志不参与自动明文还原；此前已经上传的日志继续按面板期限保留。

需要同时使用配套面板和 Agent 才能完成此次行为变更：旧 Agent 在隐私模式下仍可能停止产生和上报运行日志，旧面板仍可能丢弃运行及路由拦截日志。历史缺失日志不能补回；本地未发布版本不作为服务器更新来源。

面板密钥接口沿用原有认证范围，响应禁止缓存。机器令牌只可领取本机密钥，旧式共享节点令牌保留原有节点访问权限。文件密钥根据数据库机器编号及应用主密钥派生；恢复面板须保留原数据库和 `APP_KEY`。轮换应用主密钥时，需在 `APP_PREVIOUS_KEYS` 中保留尚有数据使用的旧密钥，直到配置、需要的备份完成迁移，且使用旧密钥的加密日志已轮转或移除；历史加密日志不会自动重写密钥。无需新增数据库迁移。

仅加密程序管理的文件；外部手工指定的共享证书和配置不自动改写。复制单独加密文件不包含密钥，但完整节点目录和有效启动凭据仍可用于向面板领取密钥。证书、历史备份、目录迁移及旧版回退的具体范围见[Agent 加密与恢复说明](../../YZ-Agent/docs/log-privacy.md)。

Agent `v2.26.1` 在保存、合并、清理和迁移配置或凭据时，将文件权限收紧为仅所属用户可读写（Linux `0600`）；安装记录也使用相同权限。已有文件曾放宽权限时，下次经这些入口保存会收紧；安装器升级同步应用。默认安装目录原有的仅所属用户可进入权限（`0700`）继续保留。这些措施限制普通系统账号读取，不限制宿主机管理员。

新版安装器通过标准输入向配置生成程序传递令牌，减少进程参数中的凭据暴露。显式选择历史版本时，通过能力探测保留其旧参数方式；历史版本不具备这项加固。

沿用原有机器字段，不新增数据库迁移。仍有机器开启隐私保护时，回滚该字段的历史迁移会被拒绝；应先正常关闭并确认节点转换完成，不能靠删除字段解除策略。不要删除并重建机器来替代普通编辑。

独立面板域名继续使用 Agent 的面板连接地址配置，HTTP 接口和 `/ws` 长连接均需可用；详见[Agent 连接地址](../../YZ-Agent/docs/log-privacy.md)。
