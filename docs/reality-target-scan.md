# Reality 目标检测

面板 `1.85.0`、管理端 `0.57.0`、Node `v2.12.0` 新增此功能，目前未发布。交互参考本地 3x-ui 固定提交 `608ef4e4010bf83e2e78328e08f77efc051ad4d7`，检测及通信代码在 YZ 项目中独立实现。

在节点编辑界面选择 Reality，并绑定运行新版本 Node 的服务器后，可以使用：

- **检测当前目标**：检查已填的伪装域名和端口。
- **查找目标**：检测逗号或换行分隔的域名、IP 或 CIDR 网段。网段使用 443 端口；域名和独立 IP 可以指定端口。留空检测内置候选。
- **使用**：把通过检测的域名和端口填回表单，保存节点后生效。密钥、短 ID、防盗用开关和其他草稿不变。

检测由所选节点服务器执行。延迟包含域名解析、TCP 连接和 TLS 握手，不代表客户端经过代理后的延迟，也不包含后续单独执行的证书链校验耗时。可用判定要求证书有效且域名匹配、TLS 1.3、HTTP/2，以及 X25519 或 X25519MLKEM768 密钥交换。这是候选可用性检查，不替代实际客户端连接验证。

网段扫描先在不发送 SNI 的情况下连接 IP，从证书中发现具体域名，再按发现的域名重新解析并发起带 SNI 的握手。结果中的延迟和 IP 对应复测的域名；该域名可能解析到不同的服务器。它不会枚举服务器上的全部 SNI，也不会自动识别节点的当前网段。

默认候选为 `www.microsoft.com:443`、`www.amazon.com:443`、`aws.amazon.com:443`、`www.samsung.com:443`、`www.nvidia.com:443`、`www.amd.com:443`、`www.intel.com:443`、`www.sony.com:443`、`dl.google.com:443`。不预设 `www.cloudflare.com:443`，仍允许管理员主动输入。

每次最多输入 64 项，合计最多 512 个地址；单个网段最多 256 个地址（IPv4 至少 /24、IPv6 至少 /120）。同一服务器同时执行一个任务，同样的在途请求复用原任务。最多 32 个并发握手，单目标 10 秒、IP 初步发现 4 秒、整个扫描最多 170 秒，任务 180 秒后超时。任务和结果暂存 Redis，最后一次交互后保留最多 8 分钟，过期后重新检测。

只检测公网地址。私网、本机、链路本地、共享地址、文档及其他保留地址会被拒绝；域名解析结果中包含这些地址时同样拒绝。连接固定到已检查的 IP，不使用环境代理。此功能没有内网放行开关，不开放新的监听端口。

任务和结果随现有五秒服务器控制请求收发，不影响原重启、升级操作。旧 Node 不声明检测能力时，管理端明确提示升级；新 Node 连接旧面板时继续原有服务。检测只改变表单草稿，保存配置仍沿用原流程。进程变化、超时和过期结果不会覆盖后来的任务。

本地验证使用独立模拟接口和本机 TLS 证书，不扫描真实公网或连接生产服务器。版本与验证结果见 [兼容矩阵](../YZ_COMPATIBILITY.md)。
