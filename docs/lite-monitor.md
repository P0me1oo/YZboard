# Lite 服务器监控接入

自动绑定与调度接入配套面板 2.12.0、管理端 0.96.0；主机监控切换仍兼容 YZ-Agent v2.35.0，无需为本次修改升级 Agent 或代理核心。旧 Agent 仍可接入，但只有升级后才会停止本机采集和发送；面板可直接停止接收其主机负载和写入对应历史。

## 使用

在“服务器管理 → 接入 Lite”填写 Lite 的 HTTPS 站点地址、站点 API 密钥，启用后点击“保存并读取”。密钥来自 Lite 的“API 密钥”窗口，保存后不会回显；后续留空保留原密钥。

- 启用 Lite 后，每分钟检查未绑定机器，通过 YZ-Agent 上报的公网 IPv4、IPv6 匹配 Lite。新机器上报地址后自动参与；尚无地址或 Lite 尚未收录时定期重试，已有未绑定机器同样参与。“按公网 IP 一键绑定”可立即处理当前唯一匹配。
- 只处理两边都唯一且 Lite 编号未被占用的匹配。共享出口、IPv4/IPv6 指向不同候选、多个候选或已有归属均显示匹配冲突；管理员在原绑定下拉框选择目标，不抢占已有绑定。
- 手动解绑会持久暂停该机器的自动匹配，避免下一分钟重新绑定；点击“恢复自动绑定”后继续定期重试，也可直接手动绑定。已绑定机器保持唯一编号关联，后台不会因 IP 变化改绑。
- 勾选 Lite 服务器后可批量导入，一次最多 200 台。导入创建服务器记录，不安装程序、不绑定代理节点；重复导入跳过已经绑定的 Lite 编号。
- 绑定或解绑成功后立即清除旧列表；后续读取失败会单独提示刷新失败，可重新读取，不需要重复提交操作。
- 成功后使用 Lite 的服务器唯一编号保持关联，名称和 IP 变化不需要重新匹配。更换 Lite 站点前须解除原绑定；站点停用或不可达时，仍可从连接窗口解除绑定。
- 取消“启用 Lite”后，页面及 YZ-Agent 监控恢复，绑定关系保留；解绑同样恢复原监控。

### 绑定并发修复（2.11.1）

自动绑定会按机器编号顺序对参与公网 IP 匹配的本地机器加共享行锁，手动绑定只锁目标机器（2.12.0 起需要同时更新自动绑定开关，因此使用排他行锁）；锁定发生在读取绑定快照之前，事务提交或回滚后释放。Lite 网络读取在事务外完成。这样可避免 MariaDB 开启快照隔离时，机器心跳更新导致绑定外键检查报错 `1020 Record has changed since last read`，短暂等待的心跳随后继续处理。

并发冲突仍保留最多三次整笔事务尝试；耗尽后返回 503 和“Lite 绑定遇到并发更新，请稍后重试。”。批量绑定及导入完整回滚，不保留半批绑定或本轮创建的机器；手动改绑失败保留原绑定。目标机器在校验后被删除时返回 409，提示重新读取。其他数据库故障仍沿用原异常处理，不冒充可重试冲突。

本修复只修改面板后端，无需迁移、重建管理端资源或升级 Agent。

## 主机监控切换

只在“服务器已绑定 Lite”且“启用 Lite”同时成立时停止 YZ-Agent 通用主机监控，包括 CPU/每核占用、系统负载、内存、交换区、磁盘和通用网卡速度。机器与其全部代理节点共用策略；仅配置接入但未绑定的服务器继续原监控，自动绑定、手动绑定和导入采用相同规则。

面板通过握手、机器发现、控制心跳和实时回执下发开关。正常机器模式在下一轮控制交换（约 5 秒）应用，无需重启；解绑或停用后按原采样周期恢复。Lite 读取失败、离线或页面无人查看不改变此开关，面板通信失败时保留上次已确认策略。

代理流量与计费、在线用户、来源 IP、连接数、设备同步、限速事件、核心/证书/健康状态、配置同步及升级/重启控制保持。Agent 自身的运行时长、协程和 GC 指标仍保留；服务器流量保护所需的专用计量继续运行，不使用 Lite 流量替换。

绑定启用期间，面板忽略旧 Agent 或在途请求中的主机指标，不新增该机器的本地负载历史，不改写最近主机负载。既有历史按原保留期清理，不删除或补写停用期间的数据；页面主机曲线由 Lite 提供。未携带主机负载的节点状态显示无负载，核心在线状态仍保留。

2.12.0 新增机器自动绑定开关迁移，默认开启，保留既有机器和绑定；首次从未接入 Lite 的旧面板升级时仍需执行既有 Lite 表迁移。只升级面板可停止历史写入，同时升级 Agent 才能停止采集和发送。

## 读取范围

服务器名称旁展示 Lite 的国家/地区国旗，优先使用 Lite 手动指定的地区，并以该地区参与列表默认排序。国旗使用随管理端打包的 SVG，不调用外部图片服务，也不向服务器名称或订阅名称插入 Emoji。

绑定服务器的负载、历史曲线和列表流量显示使用 Lite 数据；机器心跳、YZ-Agent 在线判断、运行版本和升级/重启仍使用原数据。Lite 在线状态单独显示，不能据此判定代理程序在线。

详情包括 Lite 名称、公网 IPv4/IPv6、国家/地区、操作系统、架构、处理器、核心数、内核、虚拟化、分组、标签、带宽、到期时间、公开备注，以及以下流量信息：

| 信息 | 口径 |
| --- | --- |
| 已用流量 | Lite 最新状态中的本周期上传、下载计数，沿用 Lite 的校准结果 |
| 配额 | Lite 当前周期有效配额，包含额外额度；0 表示不限 |
| 统计方式 | 上传、下载、合计、取较大值、取较小值 |
| 重置 | 原重置日、具体时间、服务商时区及 Lite 返回的下一次重置时间 |

缺失或无法识别的数据显示“—”；离线或过期状态不显示为当前负载。读取失败时显示失败，不把用量补零、不把上次读取结果当作当前数据；历史读取失败可单独重试。

现有服务器流量保护、超限自动停服、用户扣费和代理统计均沿用原逻辑。读取 Lite 的配额、用量和重置规则不写入本地流量保护字段，编辑服务器时的额度仍是原保护配置。Lite 流量不参与自动停服判断。

## 负载调度（2.12.0）

已绑定且启用 Lite 的前置成员使用 Lite 有效额度（含额外额度）、当前周期校准用量和五种统计口径，并使用 Lite 返回的绝对重置时间参与原有四种调度策略。额度为 0 表示不限；未知不等于 0 或不限。未绑定或停用 Lite 时沿用本地额度和周期；本地流量保护仍可独立撤下已超限或计量异常的节点。

Lite 读取失败、节点缺失、离线、状态超过 180 秒或未来超过 60 秒、额度/用量缺失时，调度标记数据不可用，不恢复成旧的本地额度。先前已确认的低额度状态保留；其他机器继续按原健康状态参与。周期策略只以有效的未来绝对重置时间排序，不在面板重算 Lite 的月底与夏令时；已耗尽的成员让位其他健康成员，没有其他健康入口时仍保留兜底，不因 Lite 数据缺失制造停服。心跳、端口及测速失败的成员不会因此恢复。

面板新增 `v2_server_machine.lite_auto_bind` 布尔字段。回退程序前停止新自动绑定命令；保留新增列不影响旧版读取，但旧版不提供自动匹配和暂停控制。撤销迁移只删除该开关，不删除机器、绑定或流量数据。

## 接口与存储

本实现对照 Lite 源码 `def441aa08a66fbd6bb979fbbce4c60f478b4803` 的 API：`POST /api/rpc2`，使用 `Authorization: Bearer` 站点密钥。只调用 `admin:listClients`、`common:getNodes`、`common:getNodesLatestStatus` 和 `common:getRecords` 四个读取方法，不接入远程命令、终端或文件操作。

YZboard 后端读取 Lite，浏览器只访问面板管理员接口。数据库新增 `v2_lite_connection` 和 `v2_lite_machine`，保存一套连接配置与绑定关系；密钥使用应用密钥加密。API 和缓存只返回白名单字段，不返回 Lite Agent 令牌。连接使用 HTTPS、公网解析、固定本次解析 IP、证书验证、超时和禁止重定向，只接受普通公网单播地址，排除共享、文档、多播及 IPv6 转换/隧道网段；当前不支持仅内网可达的 Lite 地址。

并发缓存未命中时，后续请求等待正在进行的读取：资料最多 22 秒，其余最多 12 秒；等待超时返回 503，可重新读取。

服务器资料缓存 60 秒，实时状态缓存 10 秒，历史查询缓存 30 秒；页面、后台自动绑定和前置调度共用缓存，不复制 Lite 的历史库。自动绑定使用独立的每分钟后台命令，避免阻塞其他定时任务；Lite 不可达时下一轮重试。调度读取失败短暂缓存 10 秒，避免多个池连续重复超时；到达 Lite 返回的周期边界时清除资料与状态缓存。历史曲线按所选 1–24 小时范围读取，最多 500 个点。Lite 的实际采样、校准和历史保留时间以其设置为准。

管理端使用 `flag-icons` 7.5.0 的 4:3 国旗 SVG，保留 MIT 许可证于 `public/licenses/flag-icons.txt`。
