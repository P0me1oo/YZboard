# 管理界面检查与修正

日期：2026-11-15。面板 2.16.8，管理端 0.98.5。开发阶段仅修改本地源码与集成资源；发布情况见后续发布记录。

已正式发布为面板 v2.16.8、管理端 v0.98.5，尚未部署。固定来源、安装包与核验结果见[发布记录](release-2.16.8.md)。以下保留开发阶段检查。

## 问题与修正

- 健康详情状态标签被“最后一个 span”选择器放大到 23px，而继承的行高只有 20px。改用明确的状态标签选择器，统一 13px 字号与 20px 行高，避免文字挤在底色里并抢占标题的视觉重点。
- 手机节点卡片的状态列采用右对齐，详情会继承该样式，长标题、检查说明及错误信息一起向右偏移。详情现在明确左对齐和行高；长标题、错误可以换行，检查图标固定宽度，延迟与单位保持单行。
- 前置负载分配的新增、编辑表单原先插在列表顶部，从列表底部编辑需反复滚动。前置池、落地主备和 DNS 配置统一使用弹窗，标题与保存栏固定，正文内部滚动。保留原字段、接口请求、成员兼容性及校验。
- 保存失败在弹窗底部显示错误并保留草稿；保存等待期间禁用重复提交和关闭。保存成功后结束列表刷新，再关闭并将焦点还给原按钮。取消、Escape 和保存均保留列表原滚动位置；列表刷新失败继续显示页面错误。
- 320 像素仪表盘标题被工具按钮挤成两行，前置负载分配页工具按钮超出可视区域；服务器卡片的完整名称组件和操作按钮挤在同一行产生重叠。手机仪表盘和前置页将工具另起一行，服务器卡片将操作排到名称下方；桌面保留原布局，其他移动卡片不受服务器样式影响。

## 检查范围

使用本地模拟接口及独立临时身份检查，未访问生产账号或执行真实节点、DNS 写操作。

对仪表盘、节点、服务器、用户、套餐、负载分配、证书、拓扑和节点设置共九个页面进行 1440/390/320 像素截图检查。用户使用独立模拟记录，套餐及负载分配的页面概览采用空状态，负载分配表单和列表另由业务场景提供有数据的检查；本记录不代表所有真实数据、主题和插件的完整联调。

最初预览服务的负载分配默认接口缺少该页面要求的数据结构，触发错误边界；检查脚本已按真实接口补齐独立模拟响应，并增加错误页识别。该问题发生在预览数据中，未据此改写产品接口或后端业务。

弹窗另覆盖 1440/1024/390/320 像素、从第 18 行进入编辑、键盘关闭、焦点返回、固定保存栏、保存等待及失败重试。健康详情覆盖 1440/390/320 像素、长中英混合标题和长检查错误。
